## 证据库业务

| 需求 | 已写用例 | 位置 | 说明 |
| --- | --- | --- | --- |
| 显式收录 | 图中存在但未收录的 Claim 不自动入库；普通 0/1 收录 | functional、business-boundaries | 核对新增库成员行为 |
| 固定 0/1 与原文 | 正误原文、非法值、字段覆盖、来源更新/删除、返回对象所有权 | functional、business-boundaries | confidence 不变，元数据状态允许变化 |
| 判定依据 | 空理由拒绝、人工理由、来源/附件、不同依据另建记录 | functional | 上游和自身核查下游可以为空 |
| 重复与冲突 | 同版本/范围/依据重复、相反判断、不同来源/Map 身份 | functional | 唯一键定义由应用选择，执行由数据库保证 |
| 语义指纹 | 数字、否定、单位、条件变化不被误当相同陈述 | business-boundaries | 不在测试中计算业务指纹 |
| 正常匹配 | 同文同范围的 0/1 候选、匹配理由、只读结果 | business-boundaries | 不自动收录目标、不更新固定判断 |
| 范围匹配 | 主体/事件/地点/时间/条件不同、未知字段、条件集合顺序 | business-boundaries | related 不等于适用；未知不默认为无限制 |
| 搜索与分页 | 0 筛选、主体/事件筛选、空库/零命中、页大小、游标绑定/过期 | functional、business-boundaries | 对应用选择的查询规则做验收 |
| 撤回与替代 | 状态、历史读取、版本、循环/越界、管理幂等 | functional、business-boundaries | 不覆写旧内容或旧判断 |
| 库引用 | 选择材料、固定摘要、撤回后的原引用、未选成员、使用记录 | functional | 验证库输入/引用契约；不重测 Host 租约 |
| 历史快照 | 清单固定、重放、成员限定、必须指定快照、工作区绑定 | functional、business-boundaries | 历史模式不成为任意读停用条目的入口 |
| 出处与使用追溯 | 版本身份、来源关系、当前/历史使用、附件保护 | functional | 深层关系导航依赖未来明确的查询契约 |
| 库独立包 | 0/1 原文、选定清单、内容摘要、附件闭包、映射、幂等 | functional、business-boundaries | 不把独立库包结果当成图组合包已验收 |

当前范围匹配测试使用明确的结构化条件：不一致候选可以排除，或标为 different；同文未知范围候选标为 unknown；完全对应标为 compatible。更复杂的区间包含、语义等价和自然语言条件推理须在产品规则明确后增加具体用例，不伪造适配层判断。

## 少量适配器与周边接口

| 边界 | 本套检查 | 保留理由 |
| --- | --- | --- |
| 业务唯一键 | 多个收录请求得到一个条目，保留各自收据 | 验证应用使用正确的键，不验证数据库锁实现 |
| 收录事务组合 | 注入提交失败，条目与收据没有部分提交 | 验证业务写入加入同一事务，不验证引擎 ACID 算法 |
| 有界查询 | 分页正确、索引观测、完整条目物化上限 | 验证查询调用路径，不做数据库通用优化器压测 |
| 工作区权限 | 本库接口的读写角色、非成员隐藏与越界 | 复用身份/成员系统，检查新增入口确实调用它 |
| 图引用/组合包 | 已写库引用协议；真正手工图引用、图/图收据/使用索引提交失败的组合原子性，以及组合包在周边接口确定后做对接验收 | 属于新库能力的接口契约，不增加 Host/数据库内部模拟实现 |

## 业务压力场景

除 small/medium/large 的规模矩阵外，新增 hotspot、large-text、zero-hit、high-hit、first-use 和 soak：测试业务选择的热点、正文大小、命中分布、首次无额外预热和持续增长。first-use 不表示清空数据库缓存；内存指标仍是采样值。场景、门槛及未执行状态见 [说明](./README.md)。
