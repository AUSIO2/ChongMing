# UC-03 建立和维护事实数据图

## 业务目标与完成条件
以节点和显式关系保存来源、新闻、事实、证据和核查结论，整批修改原子形成一个新 Map revision。

## 入口与调用者
map.create、map.delete、graph.apply，由 Workspace Editor 调用。

## 权限和前置条件
Map 创建使用 Workspace revision；其他写使用 Map revision。活动 Run 期间禁止普通图修改和删除。

## 正常调用链
`apiReadCommand → ApplicationService.dispatch → AuthService.transact → GraphService.dispatch → graphUpdateChanges → GraphStore.commit`。应用服务在 graph.apply 前核对 asset locator 的 Workspace 和 mediaType。derived-from 只允许 News→Source 或 Claim→News；split 同时生成 mentions News→Claim。

## 分支与异步续接
put 可创建或整体替换 data；更新保留 Node 创建时间并增加节点 revision。删除 Node 同时删相邻边。Edge 必须有现存端点，无自环，且 mentions/verifies 方向符合节点类型。

## 持久化读写
graphv3 单文档 CAS 更新；请求回执嵌入同一文档。Map 删除写 deletedAt，不物理删除。

## 状态迁移
每个成功命令增加 aggregate revision；更新节点/边各自 revision。创建对象从 0 开始。

## 异常、补偿和并发
同批重复 ID、put/remove 冲突、空变更、节点 kind 改变、悬空边或 8 MiB 超限均拒绝。CAS 失败返回当前版本；事务整体回滚。

## 当前实现边界
URL locator 只存储；导入 Verification 可标 stale，但没有自动依赖失效引擎。
