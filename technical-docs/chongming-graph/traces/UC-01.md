# UC-01 登录并恢复工作上下文

## 业务目标与完成条件
验证用户身份，只返回本人可见的 Workspace、Map 和个人偏好；客户端可恢复上次打开的图与节点选择。

## 入口与调用者
用户经 query 调用 app.bootstrap、workspace.list/get、map.list/get，修改偏好时调用 preferences.set。

## 权限和前置条件
Bearer token 的 SHA-256 必须命中未撤销、未过期 token，关联用户必须启用。Workspace/Map 读取最低 Viewer。

## 正常调用链
`apiCreateServer → apiReadQuery → ApplicationService.read → AuthService.read → ControlService.read / GraphService.read`。WorkspaceView 聚合成员显示名、Map 数和当前用户偏好；Map 内容先校验归属 Workspace 权限。

## 分支与异步续接
workspace.list 使用绑定 userId 的游标和 1–200 page size；偏好不存在返回 revision 0 的业务初值。客户端串行轮询 Map，每五轮刷新 Workspace 权限；这属于客户端消费策略，不改变服务状态。

## 持久化读写
普通 query 只读 control_users、control_tokens、control_workspaces、control_preferences 和 graphv3。preferences.set 在认证事务中按本人 revision upsert。

## 状态迁移
仅 Preferences revision 增长；Workspace/Map revision 不变。

## 异常、补偿和并发
无效 token 返回 401；成员关系变化后返回 404/403。preferences.set 校验引用的 Map 都属于该 Workspace，current Map 必须在打开列表中；CAS 冲突返回 409。

## 当前实现边界
服务没有推送用户视图变更；客户端以轮询恢复。
