# 010 — 公共代码抽取（1–7）

## 范围

1. `routeInstanceId` / `routeNodeId`（`map-ids`）
2. Map 层 `Priority` / `Confidence` / `ExecutionMode` 从 shared re-export
3. Catalog 三套形状并为一套（`agentName` 统一）
4. `errorMessage(e: unknown)` 公共工具
5. `executeSplitRun` / `executeVerifyRun` 合并为 `executeRun`
6. `SplitGraphConfig` / `VerifyGraphConfig` 合并为 `GraphConfig`
7. `RUN_PHASE_LABEL` 单一常量

## 设计要点

### Route id

`RouteInstruction` → Map 节点 id 的规则集中在 `electron/shared/map-ids.ts`，前后端共用。

### Catalog

唯一类型 `SubAgentCatalogEntry`：

```ts
{
  agentName: string
  module: 'split' | 'verify'
  promptPath: string
  displayLabel: string
  defaultPriority?: Priority
  description?: string
}
```

- IPC / Map 的 catalog 列表：`Omit<SubAgentCatalogEntry, 'promptPath'>`（或同形字段子集）
- `SubAgentConfig` 仍由 catalog 派生（`name` ← `agentName`，`promptPath`）

### GraphConfig

```ts
interface GraphConfig {
  defaultModel: BaseChatModel
  availableAgents: SubAgentConfig[]
  routePromptPath: string
  mergePromptPath: string
  maxConcurrency?: number
  mode?: ExecutionMode  // split 可选
}
```

split / verify 共用；`mode` 仅 split 使用。

### errorMessage / RUN_PHASE_LABEL

- `errorMessage`：`electron/shared/errors.ts`，前端 store 与 graph-service / database 共用
- `RUN_PHASE_LABEL`：`src/flow-map/labels.ts`，Header / Controls 共用，文案统一
