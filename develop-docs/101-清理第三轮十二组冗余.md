# 101 — 清理第三轮十二组冗余

## 目的与范围

处理第三轮只读复查确认的 12 组问题，保留 099、100 和现有工作区功能修改。两项行为修复为 RabbitMQ 错误类型被字符串化接纳，以及 SSE 观察回调异常被改为可重试网络错误。

## 接口与不变式

- MQ 的未知消息入口继续验证 JSON、版本、部署身份、种类、各类必填字段及活动摘要；只去掉隐式类型转换。
- SSE 的 fetch/read 失败保留网络分类；解码和帧协议错误保留原有分类；观察回调错误保持原失败，不触发网络重试。关闭、取消、超时优先级和读取器释放不变。
- 内部私有请求和身份函数接收已建立的对象类型，不将自建对象或已验证 DTO 退宽为 unknown。公开参数及服务端响应的必要验证仍在真正边界完成。
- 证据使用记录从未知存储读取时仍完整解析；可信记录的投影和本函数生成记录不重复解析/摘要。
- payload 与引用只完整校验一次后复用结果，不公开跳过验证的开关或 unchecked 入口。
- 当前 Run 的发布私有链使用 GraphCurrentRun；节点身份、类型和版本检查复用已取得的解析结果，不省略业务约束。
- UI 继续保留取消代次、身份隔离与 usageRevision；不重复验证公共网关已保证的 DTO。阅读路径只读一次；删除不可达空 pointer 分支。
- 不改变存储格式、历史数据兼容、协议、幂等重放或租约最终检查。不新增兜底、兼容转发、无依据断言或宽泛吞错。
