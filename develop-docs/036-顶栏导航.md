# 036 — 顶栏导航

## 目标

在 [`AppHeader`](../src/components/AppHeader.vue) 增加四组应用菜单：**文件 / 数据库 / 工具 / 智能体**。首期仅菜单壳与占位项；真实能力分 Phase 迭代。

## 模块

[`src/chrome/`](../src/chrome/) — 应用外壳（`chrome` 前缀）

| 文件 | 职责 |
|------|------|
| `menu-registry.ts` | 菜单项静态定义 |
| `AppMenuBar.vue` | 顶栏菜单行 |
| `AppMenuDropdown.vue` | 下拉面板 |
| `use-chrome-menu.ts` | 开合状态、占位 toast |

## 菜单路线图

### 文件

- 保存 → flush Mongo（已有 `map:save`）
- 导出图文件 → `mapGraph` + `timeline` + `chains` JSON
- 导出核查数据 → claims + `verifyResult`
- 导出结论报告 → opinion/score 汇总

### 数据库

- 连接设置 → 本地/远程 URI、测试连接
- 重新连接 / 当前连接状态

### 工具（`docCanEditNode` 范围）

- Claim 去重
- 批量改 SubAgent 参数 / 优先级

### 智能体

- CRUD 读写 [`subagentconfig/`](../subagentconfig/)（与 `catalogRead` 同源）
- 管理面板、重新加载目录
