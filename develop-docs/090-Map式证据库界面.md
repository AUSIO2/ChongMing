# 090 Map 式证据库界面

日期：2026-10-06。状态：首轮实现与验收完成。承接 084 的 Map 式界面决定和 089 的四操作后端。范围为可操作的首轮界面，不发布新版。实际结果见 [090 实施记录](./090-implement-Map式证据库界面.md)。

工作区侧栏增加固定证据库入口，Map 与库共用三维图展示、节点选择、双击单页和返回定位。抽出 GraphScene 的展示输入（有坐标的节点/连线和字符串选择身份）；普通 Map 保留真实 GraphSnapshot 及原有降级画布，库采用摘要与 entryId，不构造普通 Map。

库浏览通过 evidence.search 读取每页 25 条摘要，支持关键词、0/1、主体/事件与显式历史筛选，继续加载有界页面。选中或打开时调用 evidence.get，读取固定 Claim 内容、范围、依据、出处与状态；单页复用 DataPayloadView。搜索、详情和命令由单一窗口级状态模块持有取消/代次，切用户、服务地址、工作区及离开库时阻止旧响应覆盖当前界面。

来源 Claim 的详情增加收录入口，提交数字 0/1、明确范围、理由与可选人工依据。撤回使用当前条目 revision、理由和稳定 requestId；未知失败重试沿用原命令身份，新输入另建命令。viewer 可以浏览，editor/owner 才能收录或撤回。来源版本/工作区变化后关闭收录草稿。401 通知会话退出；不在 UI 内维护库规则或绕过公共网关。

WorkspacePage 负责切换 Map/库及装配，库特征模块拥有浏览和内容组件。Map 运行和编辑保持现有会话逻辑。库展示 fixed 0“确定错误”、1“确定正确”；撤回后可读固定详情，默认浏览排除撤回项。旧库来源可以定位到原 Map，但库单页始终读取库快照。

四个核心 API 尚无 relations；首轮图仅显示实际收录节点，不推算或伪造上下游连线。替代、关系导航、Work 核查材料和快照/导入导出继续后续阶段。本机 SQLite 无库适配时展示服务返回的不可用状态。

验证包括状态模块的切换/竞态、分页、0 筛选、权限和稳定命令重试；真实 Mongo+HTTP+公共客户端与界面状态往返；共用画布和阅读投影回归；vue-tsc、专项测试类型、架构/消息检查及差异卫生。可用浏览器时实际检查 Map/库切换、节点/单页、收录/撤回；未验证的桌面/WebGL环境如实记录。
