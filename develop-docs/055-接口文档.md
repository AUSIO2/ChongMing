# 055 — 当前后端完整接口

本文件描述055已实现的接口，替代054的开发身份和启动时传入configuration。当前公开接口为8个查询、19个命令，另有文件传输、Host内部工作接口及本机管理CLI。权威类型：[control.ts](../contracts/control.ts)、[graph.ts](../contracts/graph.ts)。旧Electron/Mapper入口还没有迁移，不适用此协议。

## 1. 启动与身份

共享Mongo必须支持事务（副本集或mongos）；单机开发可以用单节点副本集。服务强制primary读取、majority写确认。默认Mongo URI为`mongodb://127.0.0.1:27017/chongming_graph`；用`CHONGMING_MONGO_URI`指定实际副本集URI。

先显式初始化共享设置、Agent库及管理员（JSON中的名称自行填写；不必指定id，服务会生成UUID）：

```bash
npm run admin -- init --input /absolute/path/to/admin.json
npm run graph:serve
npm run host:serve -- --host-id host-a --dsh-home /absolute/path/to/host-a
```

admin.json：`{"displayName":"Owner"}`。init返回`{user:{userId,displayName,hostAdmin},tokenId,token}`，明文token只在签发时输出，数据库只存hash。共享seed是幂等初始化，重复seed不覆盖已有配置。普通用户通过HTTP创建Workspace；默认Agent库只在显式seed读配置文件。

本机尚无内部Host token时，init会生成随机值写入私有配置文件而不打印；同目录启动的图服务和Host会自动读取。模型调用仍需另行配置相应provider凭据。

图服务默认监听`127.0.0.1:4320`。公开请求用用户`Authorization: Bearer <token>`；内部Host接口用独立`CHONGMING_DATA_TOKEN`。Host与其本机图服务使用相同内部token；用户token不能代替它，内部token也不会自动成为用户。

Owner管理工作区；Editor编辑图、启动/取消Run、审核；Viewer查看、导出单图及保存本人偏好。HostAdmin管理共享library/settings，不自动获得任意Workspace内容权限。不可见资源返回404，可见但权限不足返回403。禁用用户/撤销token令后续请求401；已接受的共享Run不会因发起人撤权而取消。

用户写请求在事务内touch用户、token及Workspace私有授权围栏，撤权与图写入有真实写冲突。授权检查先于收据重放，不能用旧requestId绕过当前权限。

## 2. HTTP与公共信封

| HTTP | 地址 | 内容 |
|---|---|---|
| GET | `/health` | 无凭证进程存活检查：`{"ok":true}`，不表示模型/共享配置已就绪 |
| POST | `/api/v1/query` | `{method,params}` |
| POST | `/api/v1/command` | `{requestId,method,params}` |
| POST | `/api/v1/assets?workspaceId=…&filename=…` | 原始二进制上传 |
| GET | `/api/v1/assets/{assetId}/content` | 二进制下载 |
| GET | `/api/v1/maps/{mapId}/export` | MapBundle v3 JSON |
| GET | `/api/v1/workspaces/{workspaceId}/export` | WorkspaceBundle v3 JSON |
| POST | `/internal/v1/work` | Host领取、查询确认、续租、释放与失败 |
| POST | `/internal/v1/data/read` | DSH读取当前授权输入 |
| POST | `/internal/v1/data/propose` | DSH提交本项结果 |

JSON请求最大1MiB，UTF-8，拒绝未知字段。UUID用于Workspace、Map、Node、Edge、Run、Review、用户和requestId。Agent id是`[a-zA-Z0-9_-]{1,64}`（系统复制时生成UUID）；promptPath是稳定逻辑键，不是可写磁盘路径。工作/报告ID是不透明字符串。时间为ISO字符串，revision为从0开始的非负安全整数。

公开成功：`{ok:true,requestId,replayed,data}`。创建Map/Workspace/Agent及导入首次返回201，其他成功200。重复已接受请求返回当前可读视图及原创建ID，replayed=true。请求幂等按用户、资源作用域、requestId和规范化输入判断；同ID改输入409，不重复执行。不承诺逐字节重复旧快照。

错误：`{ok:false,requestId,error:{code,message,retryable,currentRevision?}}`。5xx retryable=true。资源删除后不通过重放复活；传输失败可原样重发，409需要重读并用新requestId提交合并后的输入。下载/导出成功不套JSON信封，失败在响应头发送前使用同一错误格式。

## 3. 全部查询

| method | params | data |
|---|---|---|
| app.bootstrap | `{}` | `{identity,settings,metadata}` |
| workspace.list | `{cursor?,limit?}` | `{items:WorkspaceSummary[],nextCursor}`，只含本人工作区 |
| workspace.get | `{workspaceId}` | WorkspaceView，含成员、Agent副本及本人偏好 |
| agent.list | `{scope,kind?}` | `{scope,revision,items:AgentProfile[]}`，完整详情 |
| map.list | `{workspaceId}` | `[{id,workspaceId,revision,name,nodeCount,claimCount,updatedAt}]` |
| map.get | `{mapId}` | GraphSnapshot |
| run.get | `{mapId,runId}` | 当前或历史完整Run，不含lease/DSH消息 |
| asset.get | `{assetId}` | ready Asset metadata |

workspace.list的limit默认50，范围1–200；cursor绑定用户，不代表跨请求全库快照。map.list当前全量返回该工作区摘要。

WorkspaceSummary：`{id,name,description,revision,role,mapCount,updatedAt}`。WorkspaceView另有`agents`、`members:[{userId,displayName,role}]`和`preferences`。Workspace资料、成员与Agent副本共用revision；私有授权围栏不改变它。

Preferences：`{workspaceId,revision,openMapIds,currentMapId,nodeSelection:{mapId:nodeId|null}}`。首次为revision=0、空数组/空对象、currentMapId=null。保存按本人独立版本，不推进Workspace.revision；引用必须属于本人可见的该工作区，currentMapId必须在openMapIds内。

bootstrap.identity：`{userId,displayName,hostAdmin}`。metadata包含version、七种promptKinds、各kind的variables有序可选变量名、scores `[0,0.5,1]`、executableKinds `["verify"]`、三个实际verify data_propose输出预览`[{kind,content}]`。配置管理支持parse/split角色，尚不表示它们已接执行器。

## 5. Agent与共享设置

scope：`{kind:"library"}`或`{kind:"workspace",workspaceId}`。library有独立集合revision；Workspace范围的Agent集合revision等于Workspace.revision；每个Agent还有自己的revision。

AgentInput：`{id,promptPath,kind,name,description,content,promptVars,tools,provider,model,defaultPriority,claimCategory}`。AgentProfile另有`{revision,deletable,updatedAt}`。

| 字段 | 语义 |
|---|---|
| kind | parseExtract / splitRoute / splitSubAgent / splitMerge / verifyRoute / verifySubAgent / verifyMerge |
| id / promptPath / kind | 创建后不可变；promptPath在scope内唯一 |
| name / description / content | 名称、能力描述和可编辑提示词 |
| promptVars | 有序、无重复变量名，必须属于bootstrap.metadata.variables[kind] |
| tools | 无重复的已声明工具名；实际实现由Host可信DSH patch注册 |
| provider / model | 字符串或null；null继承共享settings的默认值 |
| defaultPriority | high / medium / low，供路由参考；最终以批准slot为准 |
| claimCategory | data / quote / causal / null，随配置传给路由 |

只允许新建splitSubAgent/verifySubAgent。固定parse/route/merge可编辑不可删；被持久策略引用的删除会被拒绝。empty工作区没有Agent，需要明确copy配置后才能核查；library方式复制完整私有副本，新副本有新ID。

agent.copy同时检查源libraryRevision和目标Workspace.revision。merge按promptPath覆盖选中项，已有副本保留ID；replace用所选配置替换，但不得漏掉已有固定角色。同promptPath但不同kind不能借copy改变身份。修改共享库不自动覆盖已有Workspace；已运行的Run也不读取新配置。

ClusterSettings：`{revision,llm:{provider,model},tools:[{name,description}],limits:{maxAgentSlots}}`。maxAgentSlots范围1–32。仍被library/Workspace Agent引用的工具不能从catalog移除。设置没有模型密钥，也没有任意Workspace用户可指定的baseUrl。端点通过可信Host的DSH provider配置/patch设置，自定义Agent选择对应provider名称。

默认seed的Agent继承共享模型设置；管理员可在Agent上显式覆盖。冻结后的runtime profile使用实际provider/model，保留promptVars、priority/category及工具白名单。verify执行按promptVars顺序注入授权上下文，替换选中的`{{变量}}`；不把不可见News context字段注入模型，也不将用户文本再次当DSH模板解析。

## 6. 图数据与Run

GraphSnapshot=`{mapId,workspaceId,revision,name,nodes,edges,run,updatedAt}`。Node=`{id,revision,data,createdAt,updatedAt,importedFrom?,validity?}`；importedFrom=`{bundleId,nodeId,revision}`，validity为current/stale标记。当前用stale标识导入结论，不宣称已有完整的自动依赖失效引擎。

Node.data有五种：

- source：`{kind:"source",locator,label:string|null}`。
- evidence：`{kind:"evidence",content,locator,capturedAt}`。
- news：`{kind:"news",content,context:{字段名:{value:string,visibleToAI:boolean}}}`。
- claim：`{kind:"claim",content,category:string|null}`。
- verification：`{kind:"verification",score:0|0.5|1,reason,reportIds:string[],opinions:GraphReport[]}`。

locator=`{kind:"asset",assetId,mediaType}`或`{kind:"url",url}`；URL须为HTTP(S)，本阶段只存储，不自动抓取。资产引用必须ready、属于同Workspace且mediaType一致。

Edge=`{id,revision,kind,from,to,createdAt,updatedAt}`。mentions是news→claim，verifies是verification→claim，related-to可连接任意不同节点。禁止缺失端点、自环、改变已有Node.kind。允许手工独立verification及历史报告标签；历史标签不被当作待执行任务。

changes=`{name?,nodes?:{put?:[{id,data}],remove?:[id]},edges?:{put?:[{id,kind,from,to}],remove?:[id]}}`。put整体替换data，保留节点既有导入出处；删除节点同时删除关联边。禁止同批put/remove同一ID、重复put ID和空changes。图文档有8MiB保护阈值；到达阈值后仍为取消、删除和失败收尾保留余量。

Run=`{id,mode,status,configuration,operation,error?,createdAt,updatedAt}`。status为running/waiting/completed/failed/cancelled。error=`{code,message,workId}`。Run ID不可复用；一个Map同时一个活动Run，结束后保留历史。

operation=`{id,kind:"verify",targetId,status,inputRefs,route,reports,draft,review,resultNodeId}`。inputRefs=`[{id,revision}]`绑定Claim及来源新闻。

configuration=`{router,merger,agents,tools,maxSlots}`，全部为服务器解析的快照。route=`{revision,reason,slots,approved}`；slot=`{id,agentId,angle,priority,hint,tools}`，1..maxSlots项、id唯一，同Agent可承担多个角度，工具只能取其白名单子集。

GraphReport=`{id,slotId,agentId,agentName,angle,tools,routeRevision,score,reason,createdAt}`。身份及允许工具由服务端填写；tools表示授予能力，不表示每个工具实际调用过。

draft=`{id,routeRevision,reportIds,score,reason}`，merger必须覆盖全部批准slot报告，代码不投票或重算score。review=`{id,kind:"route"|"result",revision,state,decision,createdAt,answeredAt}`，state=pending/answered，decision初始null。人工模式先审route，再审result；改待审route会增加route/review版本，批准后不可改。批准结果提交已保存draft；拒绝令Run failed。

## 7. 文件与v3包

上传header必须有用户Authorization、Content-Type、Content-Length、X-Content-SHA256和UUID Idempotency-Key。主体是二进制，不是multipart。Asset=`{id,workspaceId,filename,mediaType,size,sha256,createdAt}`。单资产最多64MiB，名称仅为显示名，不作为服务器路径。

上传先完成GridFS和长度/摘要校验，再重新授权并事务发布ready记录。相同用户/工作区/Idempotency-Key及同内容复用assetId；不同内容409，删除后不复活。重放也校验传入字节。中断、摘要不符、上传期间撤权不会公开半成品。

下载含Content-Type/Length、摘要ETag、attachment文件名；当前不承诺Range续传。asset.delete使用同一Workspace授权围栏，与新增图引用竞争时不会留下悬空引用。逻辑删除立即不可读；本机assets.cleanup可回收已逻辑删除的物理blob。

MapBundle=`{format:"chongming-map",version:3,id,exportedAt,map,agents,assets}`。WorkspaceBundle=`{format:"chongming-workspace",version:3,id,exportedAt,workspace:{name,description,agents},maps,assets}`。BundleMap=`{id,name,nodes,edges}`；BundleAsset=`{id,filename,mediaType,size,sha256,contentBase64}`。Agent为上述AgentInput，排除内部管理版本/收据；Graph报告和节点出处保留。

整个JSON包含base64最多64MiB；每包至多100个Map、每图10000节点/20000边。因base64膨胀，合法单资产也可能使完整包超限，导出会明确413，不生成无法回导的包。

把v3包上传到本人Owner的stagingWorkspace后，调用workspace.import。两个格式都导入为新的Workspace。格式/字段、canonical base64、摘要、重复ID、节点/边/资产引用闭包先检查；再为Workspace、Map、Node、Edge、已打包Agent及slot生成新ID。Node/Edge的原revision数字保留，新Map aggregate revision为0；旧reportId和未知历史Agent ID保留为历史标签。导入verification标stale，附importedFrom，run=null、runHistory/leases/执行收据为空。

不可变blob准备完成后，用一个有限事务发布Workspace和所有Map/metadata；失败不出现半个工作区。相同命令重试返回原创建ID，当前权限仍要重新通过。包按白名单导出，不包含系统token、Host secret、lease、DSH Session、活跃Run或他人的偏好；不会扫描或改写用户正文中的任意文本。

确定回滚可清理本次临时blob；提交结果未知时保留私有blob，避免误删已提交文件。未引用的未知孤儿需停写维护核对，本阶段不提供在线全局GC。

## 8. Host与内部接口

Host启动/租约协议继续使用054。每Host默认容量1，多个Host可并行处理同图不同slot，DSH负责模型/工具/上下文。Host部署所需的相同tool/provider实现；本阶段没有按Host能力自动分配不同插件集合。

`POST /internal/v1/work`使用内部Bearer token，请求`{method,params}`、响应`{ok:true,data}`：

| method | params | data |
|---|---|---|
| claim | `{hostId,holderId,mapId?}` | GraphWorkGrant或null |
| read | `{mapId,workId,holderId,fence}` | `{workId,status:"ready"|"accepted"}`，可跨Run确认旧收据 |
| renew | 同read | 固定grant的新expiresAt，失效409 LEASE_LOST |
| release | 同read | `{released:boolean}` |
| fail | 同read+`{message}` | `{failed:boolean}` |

GraphWorkGrant=`{mapId,runId,operationId,workId,actor,routeRevision,hostId,holderId,fence,expiresAt,leaseMs}`。actor为router、worker+slotId或merge。每次claim用新holderId UUID，不并发重试同holder；未收到grant不执行，未知租约等到期回收。claim不承诺用户command式全局幂等。

data.read/propose还必须有`x-work-id`、`x-work-holder`、`x-work-fence`头。角色从grant解析，模型参数不含这些头。read请求`{mapId,operationId}`；data为`{mapId,runId,operationId,claim,context,configuration,route,reports,draft,review,phase,proposalId,work}`，work=`{id,actor,routeRevision,status:"ready"|"accepted"}`。context只包含授权可见字段。

propose共同字段`{mapId,operationId,id,kind,reason}`，id=workId；route另带slots，report另带routeRevision/slotId/score，merge另带routeRevision/reportIds/score。成功data为GraphSnapshot。新写入在最终Mongo更新中检查holder/fence、到期、Run与Map版本；相同已接受内容可确认重放。取消、失败、接管后的旧授权不能新增结果。

DSH仅有data_read/data_propose及本角色允许的自定义工具。每项产物提交后结束自己的进程；HITL批准route后自动派生worker。续租失败或保守截止时间到达立即Abort，await官方SDK关闭后释放。临时数据接口错误保留可继续状态；最终模型/配置错误记录Run.failed。接管读取业务快照，未提交推理/工具可能重做，不承诺外部工具副作用恰好一次。

常用环境变量：CHONGMING_GRAPH_PORT=4320、CHONGMING_LEASE_MS=15000（100–300000）、CHONGMING_HOST_POLL_MS=1000、CHONGMING_HOST_REQUEST_TIMEOUT_MS=5000、CHONGMING_HOST_ID（默认UUID）、CHONGMING_DSH_HOME（默认`.dsh-runtime/hosts/<hostId>`）。Host CLI支持--data-api、--host-id、--map-id、--dsh-home、--cwd、--process-cwd、--dsh-bin、可重复--patch、--poll-ms、--request-timeout-ms、--max-tokens、--max-rounds。

## 9. 本机管理员CLI

`npm run admin -- <动作> --input JSON_FILE`；省略--input则从stdin读JSON。下列操作没有公共HTTP入口。配置目录由CHONGMING_CONFIG_DIR指定，默认`.chongming-host`；文件0600，目录默认0700，已gitignore。环境变量优先于本机配置。

| 动作 | JSON输入 | 输出/行为 |
|---|---|---|
| init | `{id?,displayName}` | 幂等初始化缺失配置，创建HostAdmin并签发一次性返回token |
| user.create | `{id?,displayName,hostAdmin}` | Identity |
| token.create | `{userId}` | `{tokenId,token}`；只存hash |
| token.revoke | `{tokenId}` | `{ok:true}`；撤销不可因启用用户而恢复 |
| user.disable | `{userId}` | 禁用；不能禁用最后可用HostAdmin |
| user.enable | `{userId}` | 恢复用户及未撤销token，可恢复被误禁用的Workspace Owner |
| agents.seed | `{}` | 仅初始化缺失library/settings，不覆盖已有管理数据 |
| settings.read | `{}` | 脱敏Mongo显示、dataApiUrl、dshHome、secret是否配置；不返回值 |
| secret.set | `{name,value:string|null}` | `{configured}`；写入/清除本机secret，重启相关进程生效 |
| database.test | `{uri}` | 独立连接检查事务能力，失败不回显URI密码 |
| database.stage | `{uri}` | 测试成功后保存下次启动的URI，不热切正在运行的连接 |
| endpoint.test | `{url,kind:"network"|"llm",model?,secretName?}` | network发HEAD；llm发显式OpenAI兼容小请求，可能产生模型费用 |
| assets.cleanup | `{}` | `{deletedBlobs}`，仅回收已逻辑删除资产 |

secret name支持DEEPSEEK_API_KEY、OPENAI_API_KEY、TAVILY_API_KEY、CHONGMING_DATA_TOKEN。模型诊断的secretName只取两种模型key；诊断提示词独立配置于backend/prompts/admin/endpoint.json。Mongo显示会移除userinfo并隐藏所有query选项，包含证书/代理凭据也不会回显。

本机配置写入使用互斥锁和原子rename；并发写返回LOCAL_SETTINGS_BUSY，不会两次成功却丢失其中一项。若管理员进程被强杀，确认没有配置写入者后才清理该目录的configuration.lock。切库的操作步骤为停止Host和图服务、stage、使用新配置重启；失败不会回退memory数据库。

## 10. 主要错误与后续范围

400：INVALID_ARGUMENT/INVALID_JSON/UNKNOWN_METHOD；401：UNAUTHORIZED；403：FORBIDDEN/WORK_SCOPE_MISMATCH；404：资源不存在或不可见；409：REVISION_CONFLICT/IDEMPOTENCY_CONFLICT/LAST_OWNER/LAST_ADMIN/FIXED_ROLE/TOOL_IN_USE/ASSET_IN_USE/RUN_ACTIVE/LEASE_LOST；410：已删除资源；413：请求/资产/包/图超限；422：业务引用或配置不完整；503：数据库、事务能力或共享配置未就绪。

尚未接Vue/preload、产品SSE/Activity、parse/split执行、范围演进和完整自动失效判定。旧development图没有被删除或自动迁移到某个用户；正式API只接受真实Workspace UUID，迁移与最终切换需要显式处理。通用DSH运行时`/runtime/dsh/run`仍是独立本机开发能力，不是公共用户图API。
