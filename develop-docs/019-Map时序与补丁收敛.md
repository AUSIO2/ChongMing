# Map 时序错乱与匹配补丁收敛

对应审计计划：时序与补丁审计。

## 目标

1. restore/resume 就绪握手，避免静默丢 resume
2. `applyGraphProgress` runId 守卫，防止跨 run 污染
3. 统一 `allocateInstanceId`，消除全局 slotSeq
4. 收紧 graph-doc fallback（claim/opinion parent、skill auto-create）
5. HITL confirmRoute：fanout 在 interrupt 之后
6. 重建 dist-electron 与源码契约对齐

## 非目标

- MongoDB schema 迁移
- 前端 skill UI

## 关键改动

| 区域 | 文件 |
|------|------|
| 握手 | `graph-service.ts`, `types.ts`, `electron-ipc.ts` |
| runId | `graph-doc.ts`, `electron-ipc.ts` |
| ID 分配 | `map-ids.ts`, `graph-utils.ts`, `electron-ipc.ts` |
| fallback | `graph-doc.ts` |
| fanout 时序 | `graph-utils.ts` |
