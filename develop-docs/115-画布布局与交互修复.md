# 115 — 画布布局与交互修复

按用户授权修复114审计的7项确认问题，并对拖动失焦、SVG键盘焦点先复现再处理。先补针对性测试，再改实现；不引入新状态机、数据迁移或模型调用。基线工件为`test-results/115-canvas-layout-fixes/initial-source-manifest.json`及对应源码副本。

## 模块分工

- 工作区框架：WorkspaceViews固定工具栏高度并保证操作可触达，WorkspacePage提示使用受限覆盖区域，后台状态/异常反馈不增减画布布局行。
- 侧栏与拖动：AppShell、usePanelResize共同约束有效宽度，保留用户偏好，处理中等窗口无效拖动；useMouseResize根据实际复现补失焦/松键取消。
- 证据库：EvidenceLibraryView稳定关系状态、检索按钮与分页栏，结果和错误在区域内展示，不改查询/收录协议。
- 几何：GraphScene按真实宽高比取景，useCanvasPanZoom统一容器坐标，GraphCanvas修正已复现的焦点滚动；保留新增节点取景和普通状态不重置视角的既定行为。

新增高层用例分别为canvas-workspace-layout、canvas-panels、canvas-library-layout、canvas-geometry；原113保存、C03丢包/冲突、U09拖动清理和U11节点增长继续回归。各模块独立记录红绿；编译、相关回归与构建通过后再Web-only发布，保持现有Graph/Host和模型Key。

## 实施结果

生产输入共11文件变化，模型、数据、权限协议没有变化：

- WorkspaceViews固定48px工具栏；视图切换不被压缩换行，操作区可横向滚动，键盘聚焦会将按钮完整滚入可见区域。WorkspacePage把异常/来源提示放右下受限浮层，保持重试、冲突解决和关闭入口，不遮住图标签与窄屏抽屉按钮；长同步错误在固定页脚内省略显示。
- AppShell以实际宿主宽度测量，usePanelResize分离偏好与有效尺寸，共同保留至少200px中心空间；恢复/缩窗不回写用户偏好，隐藏右栏不扣预算。移除900px固定宽度覆盖，使701–900px真实可拖；700px以下继续覆盖侧栏。两个分隔条仅主键启动，useMouseResize在blur或发现主键已释放时取消未完成拖动并归还userSelect。
- EvidenceLibraryView关系栏常驻38px、检索按钮固定76px、分页栏固定46px；长说明内部滚动，重试独立可达。收录/错误浮层锚在library-content右下、分页栏上方，避免短窗口遮住筛选栏或分页操作。
- GraphScene同时考虑水平/垂直FOV，隐藏时延后fit至实际尺寸可测；移除650距离硬截断并配套调整OrbitControls交互上限，大跨度合法图仍能取景且继续缩小。原新增节点取景、普通选择/activity/resize保留用户视角的策略保持。
- useCanvasPanZoom统一滚轮和按钮的container锚点，GraphCanvas键盘focus增加preventScroll，避免祖先滚动与自定义平移叠加。
