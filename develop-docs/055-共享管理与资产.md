# 055 — 身份、共享配置与资产

054已完成DSH和多Host执行。本阶段交付正式用户/工作区权限、共享Agent库与工作区副本、个人偏好、共享非秘密设置、GridFS资产和v3导入导出，并把它们接入当前图与Run。前端、parse/split执行和产品通知流仍属下一阶段。

## 数据与执行边界

- 用户、token、Workspace、library、settings、preferences、asset metadata分别使用共享Mongo集合；Workspace内嵌members和agents，共用公开revision；偏好独立user/workspace版本。
- 用户token为随机凭据，只保存SHA-256；本机admin CLI签发时仅返回一次。用户token与内部Host token分开。
- 公开query/command及资产读写都认证。不可见资源404，可见但权限不足403。HostAdmin不自动获得所有Workspace内容权限。
- 用户mutation使用Mongo事务，条件touch用户、token和Workspace私有writeFence，使撤权/禁用/删除与最终图写入发生真实写冲突；不能仅先读权限再写另一文档。要求副本集；不降级成非原子多文档写。
- 图服务仍是普通业务核心；HTTP应用层注入事务session、授权和用户命名空间收据。内部Host工作继续用054的独立lease/fence，不执行模型时持有用户事务。
- Workspace删除在同一事务确认没有活动Run，再tombstone；所有子资源可见性按父Workspace检查。成员撤权不取消已接受的共享Run。

## Agent配置

管理DTO沿用当前可执行profile的name/provider/model/content/tools命名，增加稳定promptPath、kind、revision、promptVars、priority/category元数据。保留七种prompt kind的配置管理；本阶段只有verify实际执行。provider/model可为空，表示使用共享settings中的默认值。地址与凭据仍由已注册DSH provider部署配置负责，不让Workspace用户通过任意baseUrl把Host凭据发送到未配置端点。

固定parse/route/merge角色可编辑不可删除；只能新增split/verifySubAgent。library有独立revision；Workspace副本与资料/成员共用Workspace.revision。copy检查library及Workspace两个版本，按promptPath保留已有副本id，merge/replace都保护固定角色。共享库更新不自动改变私有副本。

run.start公开请求不再接受configuration，服务端从Workspace Agent和settings完整生成并保存冻结快照。默认JSON只作为显式管理员seed，不在每次Run读取本机默认配置。配置更新只影响未来Run，现有动态路由/自定义工具/DSH模型选择保持有效。

## 资产与包

新增source/evidence数据的asset/url locator，只提供存储与引用校验，不伪造parse执行。原news/claim/verification及意见保持。资产通过GridFS流式上传，校验长度、SHA-256和64MiB上限，完成后在短事务中重新授权并发布ready元数据；中断或失败不公开半成品。文件名不作为服务器路径。

资产删除与新增引用通过相同Workspace writeFence排序。被引用拒绝删除；删除先tombstone，不把物理chunks清理完成作为公开可见性依据。

v3 Map/Workspace包包含实际节点、边、Agent配置和引用资产内容，排除Run/lease/Session/token/secret/他人偏好。导入校验完整引用闭包、base64/摘要/大小；为Workspace/Map/Node/Edge/Agent/slot重新分配ID，保留历史报告作为出处标签，不复活执行。先完成不可变文件，再在有限事务内发布整个Workspace，失败不出现半个工作区。当前没有052中的通用validity/NodePolicy执行，包只声明本阶段真实支持的字段。

## 本机管理与初始化

提供本机admin CLI管理用户、签发/撤销token、禁用用户、显式seed Agent和配置、只写Host secret和数据库连接诊断/下次启动配置。最后可用HostAdmin不可禁用。凭据文件权限0600；普通HTTP无任意文件写入或切库入口。运行连接切换通过停止Host、修改下次启动配置、重启服务完成，不提供未经drain的热切库捷径。

原development工作区不是正式身份来源；不自动给任意请求提供开发Owner，也不删除已有开发图。新API使用真实Workspace UUID，旧开发数据的显式迁移与最终前端切换分开记录。

## 验收

真实副本集/HTTP验证token撤销、用户禁用、Viewer/Editor/Owner/HostAdmin边界、撤权与写入的最终事务竞争、最后Owner保护、偏好隔离、Agent副本和两级版本、Run冻结。验证上传中断/摘要错误/幂等、跨Workspace访问与删除引用竞争；v3包完整导入、引用重映射、回滚和旧Run不恢复。已有DSH与多Host租约回归必须保持通过；模型端点继续使用本机fixture。
