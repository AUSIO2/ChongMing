# 067 — 模块边界与运行入口拆分

按职责拆成contracts、backend/core、storage、messaging、worker、api、client以及apps。保持一个仓库和当前业务协议，不拆多个独立npm包，不改数据格式。

核心不依赖数据库/队列/HTTP/DSH实现：GraphDocument、收据、哈希和GraphStore显式接口移出Mongo；Persistence、消息服务、工作传输及URL来源读取作为端口。各存储与消息实现只实现端口，应用入口负责选配。Host使用注入的工作传输，DSH事件转换与活动上报归worker，活动授权归core。

apps/ui为桌面/Web共用Vue界面，apps/desktop为Electron Main/preload和服务入口，apps/cli为认证CLI，apps/server为协作API/Host/admin入口，apps/local为SQLite装配与运行。部署配置读取和Mongo URI脱敏分离。历史路径不留转发文件；一次性更新类型、测试、脚本和构建。

DSH插件定位基于自身模块位置；打包产物把服务bundle与插件放在service目录，通过SDK依赖的包清单bin字段发现DSH执行文件，不依赖仓库层级。桌面运行依赖只保留DSH所需闭包，验证无mongoose/amqplib及旧运行框架。

编码前保存文件映射和现有内容，移动时保留所有未提交改动。验证模块依赖图（含type import）、本机入口闭包无协作适配器、全量测试、SQLite、打包DSH、构建与既有契约审计。原生桌面点击验收仍沿用066待解锁记录，不在本轮虚报通过。
