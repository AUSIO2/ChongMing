# 060 — 管理工作台与文件流转

## 目标与基线

059 已完成节点驱动的解析、拆分、核查和暂停恢复。当前成员、Agent、模型设置及资产大部分只有后端 API；旧工作区配置升级仍需直接调用接口。本阶段将这些已有业务能力接入默认客户端，保留 059 和旧 Mapper 的已有工作区改动。

本阶段交付工作区资料/成员管理、完整 Agent 配置与共享库复制、非秘密模型/工具设置、资产列表与上传下载/来源引用，以及图和工作区导出、工作区导入。继续使用现有 Vue、typed gateway、Electron Main 凭证边界、Mongo 权限事务和 GridFS，不新增依赖。不在本阶段加入 SSE、自动托管本地服务或删除旧后端。

## 业务与权限

- Workspace Owner 管理资料、成员、Agent、删除和共享库复制；Editor 上传资产/创建来源；Viewer 只读。后端既有最后 Owner、Agent 固定角色、被引用资产与运行中删除限制保持权威。
- 共享 Agent 库和全局非秘密模型/工具设置仅 HostAdmin 可修改。界面完整保留七类 prompt、变量顺序、工具子集、provider/model继承、priority/category；固定角色不允许改身份或删除。
- 所有写请求携带现有对象版本及稳定 requestId。响应丢失重试复用已冻结参数；版本冲突展示并保留草稿，不静默覆盖。切换用户或工作区后旧响应不写入新界面。
- 成员通过已经注册用户的 ID 添加，不替用户发消息、邀请或创建账户；账户/凭证管理仍走管理员 CLI。界面显示已有成员姓名和角色。

## 文件通道

新增只读 asset.list 查询，分页返回当前工作区 ready 资产，先验权再读取；无未完成 blob、内部 storage ID 或跨工作区内容。

ClientGateway 增加受限 upload/download 能力。upload 接收稳定 requestId、workspaceId、filename、mediaType、Uint8Array，客户端计算SHA-256并调用现有二进制上传端点；download 只接受 asset/map-export/workspace-export 三类固定资源标识，不接受任意 URL 或本地路径。响应为 filename/mediaType/Uint8Array，浏览器用 Blob 保存；Electron 业务网络请求仍由 Main 执行，Renderer 不获得 token 或文件系统权限。

上传、下载与取消复用会话代次和断开语义，严格限制单文件/包 64 MiB；错误按结构化业务响应展示。Electron bridge 校验主 frame、字节类型、大小、标识与并发请求，禁止 path/URL 扩权。关闭面板或断开连接取消网络请求，已经提交的上传通过相同 requestId可确认。

资产上传后可显式创建 Source。导出包只含数据与资产，不包含 Run/lease/Session/secret；工作区导入沿用上传 bundle到当前Owner工作区→workspace.import→创建新工作区的原子发布。失败和响应不确定时保留重试身份，不自动删除可能已提交的文件；导入完成后显式清理不再需要的暂存包可复用asset.delete。

## 界面与生命周期

默认客户端增加管理入口，使用原生表单和对话框分为工作区/成员、Agent、资产、全局设置。保留当前图、选择、执行和审核，不以管理页打开/关闭改变 Run。资料变更刷新共享工作区快照；运行配置保持原 Run 冻结值，新运行使用新配置。

管理组件在用户/工作区变化时重建并取消旧请求，草稿附带初始版本。删除/替换操作先呈现明确对象与影响，由界面的显式操作提交；代码实现过程只对隔离 fixture 做验收，不操作用户真实数据库。

## 验证

沿既有测试扩展 asset.list 权限/分页、二进制完整性/上限/取消/重试、Electron未授权frame/任意URL路径拒绝、管理命令版本和参数冻结。用真实后端+fixture做成员/Agent编辑、复制、上传并引用、导出/导入和撤权回归，验证旧Run快照不变。浏览器至少960×640核对布局和实际表单流；最后跑全量测试、类型、构建及契约检查。
