# 078 — 全项目参数级中文注释

## 目的与范围

在 076 已完成函数用途注释的基础上，为全部项目自有代码的每个值参数补充紧邻声明的中文说明。范围继续覆盖 Git 跟踪的 TS、Vue、JS/MJS/CJS 源码、测试、脚本和历史可执行工件；CSS、HTML 等没有函数参数的文件不新增无意义内容。

参数说明写明当前调用中的实际角色，按需要包含来源或信任边界、业务身份、单位、可选与默认语义、所有权、可变性和生命周期。禁止只翻译参数名，例如“`value` 参数”“当前数据”；相同名称在不同回调中按其局部语义分别说明。

## 表达方式

所有值参数采用紧邻声明的块注释，具名函数、方法、构造器、函数类型、接口签名和匿名回调使用同一形式：

```ts
export function inputReadObject(
  /* 尚未通过类型和字段白名单校验的边界输入。 */
  value: unknown,
  /* 这个对象允许出现的字段名称。 */
  keys: string[],
  /* 写入错误消息的字段路径，便于调用者定位输入位置。 */
  label: string,
): Record<string, unknown> {
  // 验证普通对象及允许字段列表，返回已收窄对象，便于后续逐字段解析。
}
```

表达式箭头同样把说明放在对应参数之前；解构参数说明整个输入对象的来源，并在确有混淆时补充成员含义。零参数函数不添加参数注释。泛型类型参数不当作运行时值参数机械注释；其约束或用途只有在公开接口存在额外约定时才说明。

## 不变式与验证

只增加注释和容纳注释所需的换行、缩进，保持函数、参数、类型、修饰符、默认值、控制流、测试输入和协议不变。以本阶段开始前的工作区作为基线，对 TS/JS 及 Vue 脚本比较完整语法结构和非注释 token；Vue 模板比较禁用注释后的生成代码，样式比较去除注释后的内容。最后扫描每个参数是否紧邻中文说明，并运行类型检查、架构与消息检查、完整测试及差异卫生检查。
