## 每项审核清单

- [ ] 能从主流程解释该功能，不需要跨多个无名helper猜业务步骤。
- [ ] 名称和用途说明准确交代数据库写入、状态修改、取消等副作用。
- [ ] 类型分支先收窄，未用断言、兜底或吞错掩盖真实状态。
- [ ] 该项不变式和现有特例有测试证据；原断言未被无理由弱化。
- [ ] 已接受结果重放和新请求执行分清；已成功历史请求不被当前状态误拒绝。
- [ ] 最终持久化的版本/租约检查未因提取而变为不安全的先读后写。
- [ ] 相同改动对其他功能的影响已列出，公共规则没有被复制。
- [ ] 审核结论明确为通过、需修改或未验证；有缺口不以“测试跑完”代替结论。
