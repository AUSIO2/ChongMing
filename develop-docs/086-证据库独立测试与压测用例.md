# 086 证据库独立测试与压测用例

日期：2026-10-06。状态：测试先行，只编写用例和驱动，不实施业务、不执行测试或压测。需求见 [084 计划](./084-workspace证据库实现计划.md)。

## 1 范围

在 experiments/evidence-library-tests 中建立独立的功能测试、合成负载场景和压测驱动。测试通过明确的接入协议调用未来的真实实现；本轮不创建 SQLite/Mongo 参考实现，不用内存模型替代待实现功能，不接入现有生产 API 或数据库。

用户明确要求先写测试用例再去实现。本轮不生成实际测试成绩、性能数值或容量结论；产物状态为未执行。可进行 TypeScript 静态检查和文件/链接检查，不能将这些检查表述为功能或性能通过。

## 2 独立接入

- EVIDENCE_TEST_TARGET 指向未来的测试适配模块，导出 createEvidenceTestTarget。
- 适配模块优先建立临时 workspace、真实身份与隔离 Mongo 副本集（SQLite 仅保留可选接入口），转发实际业务调用，读取实际持久化状态并负责清理。
- 适配模块不实现收录校验、去重、摘要、撤回、冻结或导入算法。测试的语义动作映射到未来的真实服务；freeze/submit 等名称是测试协议，不要求生产新增同名 HTTP 方法。
- 缺少接入模块、工厂或必需能力时明确失败，不自动 skip，不回退内存实现，不输出空结果或假通过。
- 目录使用独立 Vitest 配置和 TypeScript 配置；未来运行不依赖整库 RabbitMQ 测试入口。

## 3 功能用例

### 职责收窄

用户明确将数据库事务/锁/持久化/崩溃恢复与已有 Host/Run 授权能力交给底层及现有框架。本套新增用例只验证证据库业务规则；保留少量适配器集成检查，确认业务去重键、条目/收据/使用索引的事务组合和有界查询正确使用现有能力，不重测数据库引擎或运行框架算法。

本轮补充正常匹配和适用范围、检索空结果与筛选、历史快照成员校验、状态幂等及替代记录、数据包固定判断/闭包。暂停恢复、Host 接管、锁机制和崩溃恢复不再列为本套待补缺口。覆盖以 [需求矩阵](../experiments/evidence-library-tests/COVERAGE.md) 为准，不以用例数量宣称穷尽。

测试输入、夹具和预期独立于业务实现。覆盖数字 0/1、错误值和理由；内容/范围/依据冻结；合法重放先于来源校验；去重包含依据摘要；并发收录唯一；相反判断冲突；撤回、替代及循环/越权；新选择与历史快照；Work 获权引用、使用索引、上下游；附件保护；导出导入摘要和身份重映射；分页、游标和索引。

除成功结果外，检查失败后持久化状态未部分变化。故障注入位于真实事务提交 seam，不能在测试适配层模拟业务结果。权限测试使用真实身份映射，workspace 不能仅由测试调用方传值决定授权。

## 4 压测场景

| 场景 | 库内条目 | 使用关系 | 请求并发 |
| --- | --- | --- | --- |
| small | 1,000 | 10,000 | 1、4、8、16、32 |
| medium | 10,000 | 50,000 | 同上 |
| large | 50,000 | 200,000 | 同上 |

这是独立证据库合成负载，不等同于 082 的 workspace 全类型节点数量。固定种子、正文大小、0/1 分布、查询命中率及读写比例；每次运行使用新隔离数据，预置阶段与正式计时分开。

工作负载包含 search、get、collect、freeze/submit 引用和 snapshot。每种操作设置有界请求量、轮数、逻辑业务操作速率、超时和总期限；并发数表示在途业务操作数，报告真实目标的执行模型，不把同步函数包装成 Promise 后声称数据库并行。逻辑操作速率不冒充 SQL/HTTP QPS，测试协议调用尝试数另行记录。

报告各操作 p50/p95/p99、成功/失败/超时/未完成数、成功吞吐、驱动进程与目标进程采样内存、真实存储大小和机器条件。当前驱动采样不宣称瞬时峰值；遥测缺项标为 unavailable，不能填 0 或算作通过。失败和清理错误必须进入最终非零退出状态。

压测前后用确定样本验证 0/1、内容与摘要不变、幂等、撤回历史、workspace 隔离和获权引用。性能阈值集中在场景配置，标为首次测量前的工程目标；未来首次运行前可按机器预算修订并记录。不可用总体平均值掩盖某个操作超过阈值。
