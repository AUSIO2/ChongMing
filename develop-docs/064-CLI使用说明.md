# 064 — 认证 CLI 与旧入口退役

当前操作说明已迁至 [CLI 使用手册（按 UC）](./077-CLI使用手册.md)，以 077 的通用数据、分支租约、`runs[]`、运行控制权和有限 plan 协议为准。

064 阶段建立了 `npm run headless --` 认证客户端，提供 `read`、`dispatch`、`watch`、`upload`、`download` 五类入口。它与桌面共享公共 API，用户凭据和 Host 内部凭据分开。旧 `list/create/run/status` 与 `--from/--to` 入口已经退役。

本文件原有 `run.start` 的 `until/expectedRevision` 示例属于历史协议，已由新手册替代。本地模式只需分支内容版本和业务参数，不使用客户端领取/续租；协作模式另外要求编辑或运行控制租约。启动运行使用有限 plan，所有写请求保留稳定请求身份；协作调用方还应按新手册维护租期。

服务启动见 [README](../README.md)，本机服务见 [065 本机运行说明](./065-本机运行说明.md)，桌面内置运行时见 [066 桌面本机模式](./066-桌面本机模式说明.md)。旧文件归档及审计仍见 064 实施记录，不表示旧源码继续参与运行。
