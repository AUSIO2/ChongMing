# 064 — 认证CLI与旧入口退役

CLI使用与桌面端相同的client/api，向正在运行的Graph API发送公开认证请求。不会启动Mongo、Host或DSH；服务部署仍见README。

## 连接与命令

设置CHONGMING_GRAPH_API和CHONGMING_USER_TOKEN，或传--url及--token-file。用户Token由管理员签发；不能使用Host的CHONGMING_DATA_TOKEN。

- npm run headless -- --help：离线帮助，无凭据或数据库也可用。
- npm run headless -- read workspace.list：列出当前用户的工作区。
- npm run headless -- read map.get --input params.json：params.json为{"mapId":"实际UUID"}。
- npm run headless -- dispatch run.start --request-id 请求UUID --input run.json：正文为mapId、expectedRevision、id、scope.nodeIds、until和mode。
- npm run headless -- dispatch run.pause --request-id 请求UUID --input pause.json：正文为mapId、expectedRevision和runId；继续用run.resume。
- npm run headless -- watch 图UUID：输出首Snapshot及后续快照/活动/刷新NDJSON。Ctrl+C只断开这个客户端，后台工作继续。
- npm run headless -- upload --workspace 工作区UUID --file source.txt --media-type text/plain --request-id 请求UUID。
- npm run headless -- download asset 资产UUID --output 新文件路径。支持asset/map/workspace，目标已存在时拒绝覆盖。

--input -读取stdin，未指定input使用空对象；JSON和文件上限64 MiB，服务器继续执行各业务接口的独立限制。写命令必须显式保留request-id：结果不确定时重用同一ID及正文，确认结果后才发起下一次写入。成功结果写stdout，结构化错误写stderr；退出码0成功、2用法错误、1请求/文件失败、130中断。

旧list/create/run/status及--from/--to时间轴参数不保留兼容转发。使用read/dispatch调用当前公开合同；所有写入遵循用户权限、revision及业务scope/until。

## 数据与部署边界

删除的是旧源码和依赖，不是旧Mongo集合。旧Mapper数据不能直接当作当前Graph数据；如需迁移，必须另做显式离线导入，不恢复模型执行现场。当前058单operation数据仍可按现有admin迁移工具升级。

桌面安装包只包含客户端构建产物，排除node_modules；已构建Main仅依赖Electron及Node内置模块，Vue等渲染依赖已由Vite打包。服务端仍通过项目安装依赖运行，安装包自动托管本地服务留待下一阶段。

旧文件（含未提交修改）的本机完整归档及校验清单见064实施记录。052历史审计索引只保存方法名、源码哈希及行数，不保留旧执行代码。
