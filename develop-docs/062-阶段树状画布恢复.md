# 062 — 阶段树状画布恢复

用户确认前端必须保留各阶段按树状分支展开。新GraphCanvas按kind独立排序形成列式列表，并省略解析/拆分/核查Agent与意见投影，是展示回退。本轮恢复来源→解析→新闻→拆分分支→事实→核查分支→意见/结论，不改变061消息队列、SSE、业务Node身份或执行语义。

## 实现

- 数据边按业务派生方向组织布局，父节点居中于后继子树，独立来源/新闻分支占不同纵向区间；各列不再独立按创建时间排列。
- 解析、拆分Agent、核查Agent、候选事实、意见都是只读画布投影，不写进数据库成为业务节点。当前Run根据route/report/draft展开，历史Verification根据已保存opinions展开。
- 历史拆分归属从现有Run历史/outputRefs/report推导为Node的只读producer注解，HTTP快照和SSE共用同一投影，避免开始新Run后分支来源消失；注解缺失时只显示可证明的数据关系或通用阶段，不编造Agent。
- 多来源共享节点只放置一次，用稳定主枝安排位置并完整保留其他关联线；相关性环不参与树递归。图的原始关系方向/身份保持，展示按处理推进方向绘制。
- 节点选择仍使用真实数据ID；投影卡显示其自身详情并可定位关联数据，绝不把虚拟ID发给后端。键盘导航/平移/缩放保持。实时增加分支时保留用户视口，提供适应全图/阶段定位。

## 验证

布局测试覆盖多新闻多事实子树、共享事实、各阶段Agent/候选/意见、空结果和历史归属、确定性/不重叠/边界。用实际Vue画布验证分支展开、投影选择与视口保持；完成类型、构建和相关/全量回归。保留既有未提交修改。
