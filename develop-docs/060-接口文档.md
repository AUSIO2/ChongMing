# 060 — 管理工作台与文件通道

本文记录060生产增量。059节点操作、暂停和审核不变；成员/Agent/Settings/资产/导入导出的业务命令沿用现有权限与事务。

## 管理入口

默认客户端登录后可打开「管理工作台」：工作区与成员、智能体配置、资产与导入导出、全局设置。切换分类保留草稿，关闭面板停止其未完成请求，不改变正在运行的图。切换用户或工作区重建面板，迟到响应不写入新界面。

Owner管理工作区资料/成员/Agent/库复制/工作区导出导入/资产删除；Editor可上传资产及引用Source；Viewer下载资产并导出当前图。共享Agent库与全局非秘密设置只有HostAdmin可修改。固定Agent角色的身份/类型/配置路径不变，不允许删除。成员添加要求已有userId，不新增用户搜索、邀请或账户创建接口。

Agent编辑保留七类提示词、变量排序、工具子集、provider/model继承、priority/category。复制显示新增/覆盖/移除清单，再明确确认merge或replace；不静默覆盖未保存草稿。写入使用所在Workspace或library的revision，Agent编辑另带自身revision。Settings有独立revision。现有Run保留冻结配置。

## 资产分页

新增 query `asset.list`：`{workspaceId,cursor?:string,limit?:number}`，返回 `Page<Asset>={items,nextCursor}`。默认50、最大200；按createdAt降序、同时间按id升序。cursor绑定工作区和排序边界，拒绝无效格式/跨工作区使用。

只返回有权访问工作区内ready资产的公开metadata，不返回未完成blob、内部GridFS定位或别的工作区内容。仍可通过 `asset.get` 读取单项；Owner删除受引用保护。新列表同时加入ClientGateway和Electron查询白名单。

## 文件客户端

`ClientGateway.upload(requestId,input,signal?)`：input为`{workspaceId,filename,mediaType,bytes:Uint8Array}`，返回`GraphSuccess<Asset>`。客户端冻结字节和元数据，计算SHA-256，用现有POST /api/v1/assets提交，Idempotency-Key保持原requestId。响应校验工作区、长度、摘要、文件名和媒体类型。

`ClientGateway.download(input,signal?)`：input仅为`{kind:'asset'|'map'|'workspace',id:UUID}`，返回`{filename,mediaType,bytes:Uint8Array}`。分别映射现有资产content、Map export、Workspace export路径；不允许传入任意URL、HTTP头或本地路径。资产按ETag校验SHA，解码后的实际响应最多64 MiB。非压缩响应检查Content-Length相等，压缩HTTP响应不把wire长度当成解码后文件长度。文件名拒绝路径分隔符和控制字符。

默认JSON请求15秒、文件传输120秒，可用显式客户端timeout配置覆盖。AbortSignal仍留在本层：断开连接、关闭面板或窗口销毁停止请求；结果已经在服务端提交时，取消传输不撤销它。

Electron增加client:upload/client:download两个受限invoke通道，preload暴露同名方法，复用主frame/sender检查和callId取消。单文件/包64 MiB，Main同时最多32个请求、其中最多2个文件传输。Uint8Array通过contextBridge/IPC传递，Main保存token并联网；保存使用浏览器原生Blob下载面，不开放Renderer文件系统。

## 导入与重试

图或工作区v3包先上传为当前Owner工作区的暂存资产，再通过workspace.import创建新的工作区。UI为上传、最终发布各自保留稳定请求身份，导入目标ID在确认之前确定。响应不确定时重试原请求；完成后显示真实工作区名称、图数和资产数，并提供打开入口。

来源引用失败保留已上传assetId，只重试graph.apply。导入包保留在资产列表，确认不再需要后可显式删除；失败或提交不确定时不擅自清理可能已提交的结果。导入后的图不恢复Run/lease/Session，也不会覆盖当前工作区。

错误继续使用ClientError结构，403/409/413等保留业务含义。未知结果期间阻止开始新的写入覆盖原重试身份；冲突显示并保留草稿，用户重新核对版本后再提交。
