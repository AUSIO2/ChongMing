## 扫描与保留依据

扫描运行目录 154 份源码及构建配置，UI 覆盖全部 features、shell、composables、state、presentation、router 和入口；业务覆盖全部模块与应用装配；运行适配覆盖存储、消息、HTTP、Host/DSH、桌面、平台、脚本及配置。公共契约和端口逐项核对默认值与调用约定，并读取测试、实验目标及 CLI 的实际调用者。最终 RuntimeMessage 在源码、测试及实验中的无引用成员为零。

保留真实 HTTP/IPC/文件/模型/存储输入解析、授权栅栏、收据优先顺序、CAS、租约最终提交、摘要/容量/授权集合和固定历史内容约束。保留文件及 localStorage 失败、不可用 WebGL 的 SVG 降级、临时 MQ 重连、显式迁移和诊断写入故障处理。合同明确允许缺省的 publication、可选字段和未建立连接仍有各自真实语义。

适配独立 Mongo 测试目标时，将故意坏值放回生产查询解析边界，未删除坏输入断言或放宽业务预期。UI 交叉审查和业务交叉审查均确认必要检查及副本隔离仍保留。
