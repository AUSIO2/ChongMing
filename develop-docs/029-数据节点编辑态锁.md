# 029 — 数据节点编辑态锁

## 背景

`docIsParamLock` 仍用全局 `runPhase` 锁整图，与多根 Map / Timeline 并行冲突。

## 目标

两层判据：

1. **拓扑后继**（常态）：数据节点无工艺后代 → 可改正文；无更右数据后代 → 可配 route；SubAgent 无数据后代 → 可改 params。
2. **Run scope 叠加**：`running` 时仅锁 `activeNodeId` / `timeline.activeScope` 向上追溯的子树。

## 函数清单

见 [`029-implement-数据节点编辑态锁.md`](./029-implement-数据节点编辑态锁.md)。

## 边界

- workerOut claim 算后继数据；claim 正文以 `dataPhase === 'workerOut'` 为前提。
- invoke 重配 route 依赖 `projDeleteSubtree`（confirmRoute gate）。
- `docUpdateRunEnd` 后 `runPhase → idle`，不再 completed 全局锁。
