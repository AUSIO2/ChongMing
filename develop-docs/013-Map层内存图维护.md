# 013 — Map 层内存图维护

## 职责

Map 层把 LangGraph 事件与人的 CRUD 翻译整合成**一张按 newsId 维护的内存图**（`MapGraphDoc`）。UI 只读 `MapSnapshot`。

## 节点与工具

- 节点：`news` | `subAgent` | `claim` | `opinion`（有 params）
- 工具：`invoke` | `validate` | `save`（无参，挂焦点；对应 gate `confirmRoute` / `merge` / `save`）

## 存储

进程内 `Map<newsId, MapGraphDoc>`。刷新丢失；再进入时从 DB bootstrap idle 图。

## 更新

- interrupt → `applyInterrupted` 增量 upsert 节点/焦点/draft
- progress → running，清焦点
- CRUD → 改节点并 `syncDraftFromNodes`
- continue → `buildResumePatch`（`canWriteRouteInstructions`）后 resume
