# 104 — 全库 50 个确证主题修复

依据 [103 审计报告](./103-全库审计/audit-report.md) 和 findings.json，修复全部 50 个根因主题及其 60 条分区记录，包含 14 组行为问题；证据不足项不动。此次用户已授权修复生产、测试和工具代码并运行相关测试。

## 范围与不变式

先保存当前工作区可恢复快照及哈希，保留所有既有未提交与未跟踪工作；103 审计工件冻结。实现按文件所有权分成领域、运行边界、UI/客户端、证据/测试基础设施四区，跨区主题分别记录原始条目，不以部分位置修改冒充闭环。

必要的输入/持久化/协议边界、鉴权与写栅栏、Receipt 优先、CAS、重映射后新值校验、真实可选/历史值、异步代次与资源归属必须保留。证据不足的旧记录回落、插件独立端口、跨进程租约错误、两处清理双失败及未证明的 UI 指针问题不改。

## 实施方案

- 在动态 JSON 字典的构造和读取位置建立自有字段语义，支持合法原型同名键；固定 schema 关键词与 UUID 映射不机械替换。
- 在真实入口建立 UTF-8、标识类型、响应必需日期和未知空键的边界；同值同阶段已解析结果明确交接，消除重复解析、克隆、遍历和不可达分支。不用类型断言制造可信值。
- 绑定工作授权与 Operation 后再读取外部来源；保持跨异步阶段的租约/CAS 复核。Run 领取结果绑定选择意图并正确交接重复授权。
- 保留来源引用具体展开路径，校验实际父对象媒体约束；附件保留已经验证的 bytes，避免二次完整计算。
- 错误清理由现有所有者处理，保留主错并记录次错，完整清理自有资源；初始化时及时取得清理责任。活动拖动在卸载时注销监听，正常结束仍保存布局。
- 枚举使用独立于 JSON 值字符串化的选项身份。修正假绿测试与错误端口假设，删去确证退役工具形状和恒假回落。

不新增依赖、兼容版本探测、猜测性默认或大范围严格协议校验。共享内部接口如需调整，同时更新真实调用者；不变更公开协议与存储格式，不迁移数据。

实施补充：生产 TypeScript lib 使用 ES2021 声明原生 AggregateError，编译 target 不变。交叉复核发现的同根遗漏纳入原主题，不增加主题计数；未列入 50 主题的既有浏览器断言/产品语义冲突单列实际结果，不为全绿改写既有保存流程。

## 验证

行为修复优先补充外部可观察回归，覆盖合法对照及被拒绝的真实边界；低影响整理复用已有测试。先分区测试，再运行架构/消息检查、完整类型检查、Node/Vitest 相关及总体回归、浏览器相关测试和桌面运行验证（按实际执行条件如实记录）。测试失败追踪根因，不能加回默认或吞错使其通过。交叉审查最终差异，逐一对账 G01–G50 及分区条目，记录必要保留项未动。
