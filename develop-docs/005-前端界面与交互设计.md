# 前端界面与交互设计文档 — 简单、严肃风格

## 1. 设计美学与风格设计 (Aesthetics & Style)

根据系统定位，前端界面放弃任何浮夸的霓虹或过度装饰的动效，采用**极简、严肃、专业**的报表和工作台风格：

*   **色彩系统 (Palette)**：
    *   **主背景**：浅灰色（Light Mode `#F9FAFB`）与深铁灰（Dark Mode `#111827`），对比度高，保护视力。
    *   **主色调**：深邃蓝/钢青色（Steel Blue `#2563EB`），用于核心按钮、活动步骤指示。
    *   **状态警示色**：
        *   `0 / false`：淡砖红（`#EF4444`），严肃警示。
        *   `0.5 / uncertain`：中性灰或暖沙色（`#6B7280` 或 `#F59E0B`）。
        *   `1 / true`：深森林绿（`#10B981`）。
*   **字形排版 (Typography)**：
    *   界面 UI 采用清晰的无衬线系统字体（`system-ui, -apple-system, BlinkMacSystemFont`）。
    *   新闻正文阅读采用高辨识度的衬线字体（如楷体、宋体或 Georgia），字距与行高加大（`line-height: 1.7`），保证文字事实校对的舒适性。
*   **组件控制 (Controls)**：
    *   扁平化边框，去阴影化，强调内容的边界与排版。
    *   操作控件（复选框、下拉选择器）使用系统原生或高对比度的严肃组件，无多余微动效，点击即时响应。

## 2. 界面布局结构

采用**双栏工作台模式**，左右结构，并在右侧面板提供 **[ 工作台 (Workspace) / 画布 (Flow Canvas) ]** 的双模式切换开关，供用户根据习惯选用：

```
+-------------------------------------------------------------------+
| 崇明 | 事实拆分与核查系统                    [ 切换：工作台 / 流程图 ]     |
+-------------------------------------------------------------------+
| [ 新闻列表 ]                   | [ 右侧控制面板: 拆分与核查流程 ]  |
|                                |                                   |
| 1. 新闻原文与上下文区          | 2. (双模式可切换展示)             |
| - 上下文列表 (表格展示)        |                                   |
| - 内容主体 (可选择高亮事实)    | A. 工作台模式 (Workspace)         |
|                                |    - 节点进度链指示器 (Step-flow) |
|                                |    - 垂直卡片表单 (表单修改)      |
|                                |                                   |
|                                | B. 流程图模式 (Flow Canvas)       |
|                                |    - 拓扑关系节点图               |
|                                |    - 激活节点展示卡片表单         |
|                                |                                   |
|                                | 3. 流程操作区                     |
|                                |    [ 提交修改并继续 ] [ 自动/手动 ] |
+-------------------------------------------------------------------+
```

### 2.1 A 模式：工作台模式 (Workspace)
- **节点进度链 (Step-flow)**：简明的水平步骤指示器。当前运行到的步骤以高亮蓝色标记，未运行到的步骤呈灰色，暂停步骤有闪烁提示。
- **垂直卡片表单**：列表式排版，表单输入框分段对齐。字段包含：优先级下拉菜单（High / Medium / Low）、提示词微调 Hint 输入框、拆分或核查结果项（可新增、删除）。

### 2.2 B 模式：流程图模式 (Flow Canvas)
- **拓扑节点连接图**：在控制面板区域以精炼的拓扑图线条（SVG/Canvas）绘制 LangGraph 节点连线状态：
  `loadNews` -> `route` -> `dynamicFanOut (Send)` -> `subAgent` -> `merge` -> `save`
- **节点状态色彩**：已执行节点为深灰色（或绿色勾），未执行为浅灰色虚线，当前正在执行/挂起节点为蓝色实线及呼吸琥珀色。
- **交互表单**：双击任意已激活或暂停的节点，该节点卡片向下滑出或浮现垂直配置表单，使用户在此节点内部直接做修改调整。

## 3. 运行模式切换 (Runtime Mode Switch)

*   **界面提供“手动步进（人在回路）”与“自动执行”状态切换开关**。
*   在流程运行中，用户可以随时在面板上切换开关：
    *   切为“自动执行”：前端在收到 `graph:interrupted` 时，自动在回调里调用 `graph:resume` 并传入 `null`，使图无缝运行到终点。
    *   切为“手动步进”：图在下一个中断点暂停，等待用户人工操作。
