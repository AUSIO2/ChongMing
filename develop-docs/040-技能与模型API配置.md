# 040 — 技能与模型 API 配置

## 目标

- 内置技能注册表 + 智能体编辑多选表单（替代逗号分隔 `tools`）
- 全局模型 API（userData 优先于 `.env`）
- 智能体可选 `model` 字段，未填回退全局
- 技能 API Key（如 Tavily）在全局设置配置

## 模块

| 模块 | 路径 |
|------|------|
| 应用设置 | `electron/shared/app-settings.ts` |
| 技能元数据 | `electron/skills/registry.ts` |
| IPC | `app:*` / `skills:list` |
| UI | `SkillMultiSelect.vue` / `AgentSettingsPanel.vue` |

## 模型回退

`agentCreateModel(overrideModel?)`：userData/env 提供 apiKey + baseUrl；`overrideModel ?? settings.model`。

## 技能

产品用语「技能」= 代码 `tools` / Map `activeSkill`。持久化仍为 `tools: string[]`。
