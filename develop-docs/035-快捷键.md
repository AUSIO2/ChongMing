# 035 — 快捷键（节点导航 + 运行/继续）

## 目标

1. **↑ ↓ ← →**：在拓扑图上按布局坐标移动选中节点（↑↓ 可跨源链）
2. **⌘ Enter / Ctrl+Enter**：Timeline 运行或继续（与主按钮一致）

## 模块

| 路径 | 职责 |
|------|------|
| [`src/flow-map/layout-nav.ts`](../src/flow-map/layout-nav.ts) | `layoutFindNeighbor` — 纯布局导航 |
| [`src/shortcuts/`](../src/shortcuts/) | 键盘监听、忽略规则、运行键检测 |

## 导航算法

基于 [`layoutReadSnapshot`](src/flow-map/layout.ts) 的 `depth`（列）、`y`（行）：

- **↑↓**：同列 `depth` 优先；无同列邻居时全局 `y` 最近邻（可跨源链）
- **←→**：`depth` 最近左/右列；tie-break `|y差|`
- **无选中**：`(y, depth, id)` 最小节点

## 运行/继续

| runPhase | 动作 |
|----------|------|
| idle / error / completed | `runTimeline()` |
| interrupted | `continueStep()` |
| running | no-op |

`textarea` 内仍响应 ⌘↵；普通 Enter 换行。

## 验收

- 方向键在双源链、多 claim 场景行为符合布局
- ⌘↵ 与 Timeline 主按钮等效
- `npm run test:map` 含 `layout-nav.spec.ts`
