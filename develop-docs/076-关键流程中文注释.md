# 076 — 全项目中文注释

## 目的与范围

用户进一步明确要求全部项目代码，上一轮只覆盖 14 个文件不足以完成任务。本阶段逐一检查所有 Git 跟踪的项目自有代码（当前 154 个 TS、Vue、JS/MJS/CJS、CSS、HTML 文件），包含运行代码、协议类型、构建与检查脚本、测试及历史开发文档中的可执行代码。依赖目录和生成产物不属于自有源码；JSON、锁文件等不支持注释的纯数据文件保持原格式。

上一轮已处理的路径继续保留并检查遗漏：

- `backend/application/graph-application.ts`：服务装配、查询授权、写事务和用户级幂等。
- `backend/modules/graph/graph-service.ts`：图变更、收据重放、版本提交和 Work 租约。
- `backend/execution/host-worker.ts`：领取、执行、续租、重试和关闭。
- `apps/ui/state/client-session.ts`：会话切换、旧响应隔离、订阅重连和偏好保存。
- `backend/modules/graph/run-state.ts`、`work-state.ts`：Run 推进、产物接纳、阶段工作与授权校验。
- `backend/modules/identity/identity-service.ts`：身份读取、事务与授权写栅栏。
- `backend/modules/assets/asset-service.ts`：数据包导入与提交失败后的资源清理。
- `backend/adapters/storage/mongo/graph-store.ts`、`sqlite/graph-store.ts`：最终版本/租约检查与原子提交。
- `apps/desktop/local-service-process.ts`、`connection-manager.ts`：本机子进程与连接切换生命周期。
- `client/graph-client.ts`：请求取消与事件流读取。
- `apps/ui/features/graph/graph-layout.ts`：图节点的阶段树布局。

本阶段完整覆盖每个文件的函数、方法、构造器及回调，替换模板化用途说明。声明文件和协议补充职责及接口含义；Vue 模板、CSS 和 HTML 补充必要的结构说明。每一条说明均依据实际实现，不用函数名拼接模板凑数量。

## 接口与不变式

只修改注释及其必要换行，保持函数名、类型、导出、控制流、协议和运行行为。函数用途写在函数体开头，表达式箭头使用相邻块注释；已有英文原因说明按实际实现改写为中文。说明以当前实现为准，不将期望行为写成已有保证。

## 实施与验证

逐文件阅读实现及相关调用，替换空泛说明，补充非显然的顺序和副作用。按不重叠目录并行处理，建立完整覆盖清单。对 TS/JS 及 Vue 脚本比较修改前后的语法结构和词法内容；Vue 模板与样式核对去除注释后内容。运行类型检查、架构/消息边界检查及完整测试。此轮不新增行为测试、不实施 075 的结构重构、不提交或推送。
