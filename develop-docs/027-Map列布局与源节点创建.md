# 027 — Map 列布局与源节点创建

## 背景

阶段 B 验收暴露：列未按阶段对齐、新建默认 `__news_root__`、导入预渲染整条源链、解析完成后误读为全流程完成。

## 目标

1. **列枚举** `MAP_COLUMN`：0 源 · 1 解析 · 2 新闻 · 3 拆分 · 4 事实 · 5 核查 · 6 意见
2. **布局** `layoutReadNodeColumn` 定 x，parent 子树定 y
3. **空 Map**：`mapCreate` 不写占位 chains / 新闻节点
4. **源→新闻**：走标准 HITL fan-out（`graphBuildHitl`），`route` 为 **mock 解析槽**（`graphCreateMockRoute`，无 LLM，固定 1 条 `parse#1`）；`confirmRoute` 后人审 → `fanout_spawn` 投影 `parseAgent` → worker → merge(1:1) → validate → save → `news`
5. **完成态**：`0-1` 完成后提示「点运行执行拆分」，主按钮可继续 `1-2`

## 不在本阶段

- 画布点击创建非源类型节点
