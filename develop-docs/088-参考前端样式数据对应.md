### 用户统一视觉要求的适配

参考折叠画布实际为 `#f0ede5`，展开阅读为 `#fffdf8`。本项目 Map 与单页的主内容面统一使用 `#fffdf8`，`#f0ede5` 作为外围背景。`#f6f1e8` 只表示同一主题中的关联材料区域，不建立第二套视图主题。

二维画布的节点底色对应 --surface，边框对应 --line，选中面对应 --accent-soft，聚焦线对应 --accent。未来三维背景与材质仍读取同一语义色；用透明度和层次处理密图，不另设宇宙色板。

### 正文 19px 设置的实际覆盖问题

[contracts.js](https://github.com/mrsouth132-prog/ChongMing-Frontend/blob/fab7b468abfd89cc883800aba8d9bee1c1a2afbb/contracts.js) 默认 articleSize=19，[handoff.css](https://github.com/mrsouth132-prog/ChongMing-Frontend/blob/fab7b468abfd89cc883800aba8d9bee1c1a2afbb/handoff.css) 写 `body .article-body {font-size:var(--article-size,19px)}`。但 `[data-theme=folio] .article-body` 的优先级更高，实际宽屏为 18px；紧凑媒体查询进一步成为 16px。

三种采样窗口均有 --article-size=19px，正文计算值却为 18/16px。本对应按看到的效果取值，不能把“默认设置 19”写成“实际生效 19”。目标使用一处明确的正文变量及紧凑覆盖；不复制多层覆盖冲突，字号设置功能另按产品范围决定。

### 容器及媒体规则

- 视口 ≤1150px：正文 16px、标题 25px、正文 padding 24px；主要次级按钮 13px，操作区收紧。
- 视口高度 ≤740px：正文顶部 padding 20px。与上述宽度规则组合，产生两组紧凑采样的 `20px 24px 24px`。
- 正文容器 ≤420px：左右 padding 20px，并隐藏不必要计数。用容器宽度而非总窗口宽度决定，当前左栏宽度和原参考不同。
- 关联栏容器 ≤360px：左右 padding 16px；因此两个采样窗口的关联 padding 比未触发容器规则时更窄。
- 页面不产生外层横向滚动；正文、关联区和导航在所属区域滚动。单页自身为平齐的 0 圆角阅读面，不恢复已被 folio.css 取消的悬浮泡泡布局。

## 7. Hover、焦点与动效

- 主按钮 hover：原强调色与黑色混合 88%/12%；次级/轻操作 hover：柔和强调面。
- 可聚焦控件：2px 强调色轮廓，普通 offset 4px，输入 offset 2px；SVG 节点可保留清楚的强调描边，不叠加不可见轮廓。
- 禁用 opacity=0.45；已看标记、选中、执行错误和内容判断各自保留文字，不仅靠颜色。
- 原 --move=420ms 是部分几何过渡的参数，不是所有操作的统一动画时长。按钮有 120–140ms，详情 JS 动画有 180ms；避免把旧 reader 气泡展开逻辑作为新 3D 转场模板。
- prefers-reduced-motion 或用户减弱动画时关闭几何位移与持续效果；两个视图共享这项表现，不增设另一套主题。

## 8. 数据文件与验收

JSON 保存 24 项现有变量对应、27 项建议角色变量、22 组组件样式，以及三种尺寸的完整原参考计算样式。新变量是候选实现清单，A3 只声明实际消费的角色，不预先注入所有专业展示变量。

现有根变量名称尽量复用；新增 reader/evidence/导航角色放在对应组件或共享样式，保持 CSS 局部、单一来源。样式数据文件不被生产入口 import，不建立样式 Mapper 或新运行时依赖。

087 的 B14 浏览器场景细化为：

1. Map 与单页主背景均为目标纸色，强调/正文/状态色读取同一变量。
2. 宽屏正文 18px/标题 32px，紧凑正文 16px/标题 25px；完整内容不被摘要替代。
3. 主正文、核查侧正文、引用文字按不同角色使用字号，不一律 18px。
4. 实测盒尺寸/可点击高度、SVG 焦点和内部滚动；不要为每个 CSS 常量新增镜像单元测试。
5. 容器查询和源参考尺寸适配后仍无外层溢出，管理功能和原授权行为不变。

本次仅完成参考样式采样、对应文档及 JSON，生产 style.css 的摘要保持不变；没有实施 087 的新界面或测试框架。参考应用的样式采样不能替代未来新 Vue 界面的业务、浏览器和性能验收。
