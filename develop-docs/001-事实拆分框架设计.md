# 001 — 事实拆分框架设计

> 创建时间：2026-06-30

## 概述

实现事实拆分模块的纯框架代码：类型定义、Mongoose 数据层、prompt 加载器、扇出/汇聚协调层。不包含任何具体业务逻辑（prompt 内容、agent 实现）。

## 1. 数据模型

### 1.1 单文档模型

一个 MongoDB 文档 = 一条新闻 + 所有拆分结果。

```
NewsDocument
├── _id: string                  # 唯一 ID
├── content: string              # 原文
├── context: NewsContext         # 环境上下文
│   └── [key]: ContextField
│       ├── value: T             # 字段内容
│       └── visibleToAI: boolean # AI 可见性
├── claims: SplitClaim[]         # 拆分出的事实（嵌入子文档）
│   └── claimId: string          # 文档内局部编号 "1", "2", ...
│       content: string
│       category?: string
├── splitMeta?: SplitMeta        # 拆分过程元数据
│   ├── model: string
│   ├── subAgentResults: SubAgentSplitRecord[]
│   ├── rawMergeResponse: string
│   └── splitAt: Date
├── createdAt: Date
└── updatedAt: Date
```

### 1.2 引用规则

- 文档：`news-20260630-001`
- 单条事实：`news-20260630-001#1`（文档 ID + `#` + claimId）
- context 不冗余存储，从父文档读取

### 1.3 TypeScript 类型

定义位置：`electron/fact-extractor/types.ts`

```typescript
export interface ContextField<T = string> {
  value: T
  visibleToAI: boolean
}

export interface NewsContext {
  [key: string]: ContextField | undefined
}

export interface RawClaim {
  content: string
  category?: string
}

export interface SplitClaim {
  claimId: string
  content: string
  category?: string
}

export interface SubAgentSplitRecord {
  agentName: string
  claims: RawClaim[]
  rawResponse: string
}

export interface SplitMeta {
  model: string
  subAgentResults: SubAgentSplitRecord[]
  rawMergeResponse: string
  splitAt: Date
}

export interface NewsDocument {
  _id: string
  content: string
  context: NewsContext
  claims: SplitClaim[]
  splitMeta?: SplitMeta
  createdAt: Date
  updatedAt: Date
}

export type VisibleContext = Record<string, string>

export interface PromptConfig {
  description: string
  content: string   // 含 {{varName}} 占位符
}

export interface SplitSubAgent {
  name: string
  promptPath: string
  buildPrompt(content: string, visibleContext: VisibleContext): string
  parseResponse(raw: string): RawClaim[]
}

export interface SplitMainAgent {
  promptPath: string
  buildPrompt(content: string, subResults: SubAgentSplitRecord[]): string
  parseResponse(raw: string): RawClaim[]
}

export interface AIProvider {
  name: string
  complete(prompt: string): Promise<string>
}
```

## 2. 数据库层

### 2.1 技术选型

- **ODM**：Mongoose 8.x
- **开发环境**：mongodb-memory-server（零安装，进程内嵌入）
- **生产环境**：本地 MongoDB 或 MongoDB Atlas
- **切换方式**：仅改连接字符串，代码零修改

### 2.3 Mongoose Schema

```typescript
// context 用 Map<String, ContextFieldSchema> 存储，支持动态 key
// claims 用嵌入数组，不单独建集合
// timestamps: true 自动管理 createdAt/updatedAt
```

Schema 要点：
- `_id` 为用户指定的 String（非 ObjectId）
- `context` 用 `Map` 类型映射动态 key
- 所有子文档 `_id: false` 避免多余 ObjectId
- `timestamps: true` 自动管理时间字段

## 4. 扇出/汇聚协调层

定义位置：`electron/fact-extractor/extractor.ts`

### 4.1 FactExtractor 类

构造参数：
- `provider: AIProvider` — AI 调用
- `subAgents: SplitSubAgent[]` — 多个拆分视角
- `mainAgent: SplitMainAgent` — 汇总合并

### 4.2 split(newsId) 流程

```
1. 从 MongoDB 读取 NewsDocument
2. 提取 visibleToAI: true 的 context 字段 → VisibleContext
3. 扇出：并发调用所有 SubAgent
   - 每个 SubAgent: buildPrompt → AIProvider.complete → parseResponse
   - 收集 SubAgentSplitRecord[]
4. 汇聚：调用 MainAgent
   - buildPrompt(content, allSubResults) → AIProvider.complete → parseResponse
   - 得到去重合并后的 RawClaim[]
5. 分配 claimId（从 1 递增）
6. 将 claims + splitMeta 写回文档
7. 返回更新后的 NewsDocument
```

### 4.3 错误处理

- 文档不存在：抛出错误
- 单个 SubAgent 失败：不影响其他 SubAgent（Promise.allSettled 可选）
- AI 调用失败：保留 rawResponse 用于调试
