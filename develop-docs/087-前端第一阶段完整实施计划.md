## 1. 第一阶段的完成目标

交付一个可操作的 Vue 工作台：两个视图共用视觉与选中数据，Map 中选择节点可打开基础单页，返回保留当前 Map 的缩放、平移与选择，再次打开同一节点恢复阅读位置。

本计划最初以二维画布验证交互。用户查看实际预览后明确要求 Map 立即呈现 3D，因此实施中已提前加入 Three.js 的真实三维渲染与相机交互；密图聚合、5 万节点性能验证仍属于 B 阶段，全工作区跨图查询属于后续接口阶段。第一阶段不新增 Mapper、Timeline、业务节点类型或后端调度能力。

具体交付：

颜色、字体、组件尺寸与参考仓库的最终值按 [088 样式对应](./088-参考前端样式数据对应.md) 及 [JSON 数据](./088-前端仓库样式对应数据.json) 实施。该对应已用浏览器采样核对，生产 CSS 已开始按对应值统一；不要把默认设置 19px 当作参考正文的实际 18/16px。

1. 统一背景、字体体系、强调色、状态色、按钮、分隔布局与选中态。
2. 工作区/Map 导航、图标签和现有管理/运行入口继续可用。
3. 基础单页显示标题、精确类型/版本、完整内容及一跳关联材料。
4. 鼠标、键盘完成选择、打开、返回，加载/空/错误状态均有明确出口。
5. 同节点切换模式不丢编辑草稿，不改变后端 Run、租约、订阅和审核。
6. 用真实 Vue 页面和实际会话模块验收，测试网关替代外部服务；不是另做一份静态仿制页面。

### 明确边界

- 当前 Map 内的模式往返保证视口恢复；切换到另一 Map 仍采用现有画布初始化规则。本阶段不新增跨 Map 相机缓存或远端布局偏好。
- 阅读位置按用户/工作区/Map/节点隔离，在本次会话保留；登出、换用户或换工作区时清理。切 Map 不把旧正文展示为新 Map 内容。
- 只保证同节点切模式保留 NodeInspector 草稿。现有切节点/切 Map/节点消失的草稿处理不在本阶段改写，不承诺新增跨节点草稿自动保存。
- 新单页是只读展示；编辑仍通过现有 NodeInspector 和 graph.apply。运行、审核与管理继续使用既有组件和会话动作。
- 多 Map 夹具验证导航身份，不能作为生产跨图引用和全库查询已完成的证明。

## 3. 状态、身份与交互约定

### 3.1 单一数据来源

- 远端数据、当前工作区/Map、selectedId、Run 选择和权限：仍由 client-session 拥有。
- 模式 `map | page`、已打开的页面身份、阅读位置：由 use-workspace-view 拥有。
- 三维旋转、平移和缩放：由 GraphScene3D 内的相机与 OrbitControls 拥有；同 Map 切模式不重新挂载场景。旧 GraphCanvas 只在 WebGL 不可用时回退。
- 临时键盘焦点、待聚焦目标和 DOM 恢复代次：由对应组件拥有。
- 编辑草稿：仍归 NodeInspector；不复制到阅读页。

不存另一份可写 GraphSnapshot，不维护第二个业务 selectedId。页面身份是阅读导航的目标，不是另一套节点选择状态。

### 3.2 拟用前端类型

以下为拟实现的 UI 类型，不新增公共后端协议。

~~~ts
interface NodeIdentity {
  workspaceId: string
  mapId: string
  nodeId: string
}

type WorkspaceViewMode = 'map' | 'page'

interface ReaderBookmark {
  scrollTop: number
}

interface WorkspaceViewContext {
  userId: string | null
  workspaceId: string | null
  mapId: string | null
  selectedId: string | null
  selectedNodePresent: boolean
  loading: boolean
}
~~~

context 来自当前会话的只读 computed，selectedNodePresent 还必须确认 snapshot 属于当前 workspaceId/mapId。阅读缓存内部使用用户身份和 NodeIdentity 的完整键，不以 nodeId 单独索引；不保存 token、payload 或快照。

### 3.3 操作语义

| 操作 | 行为 |
| --- | --- |
| 单击节点/Space | 选择节点；同一个 selectedId 不重复提交选择动作 |
| 双击节点/节点上 Enter/「打开单页」 | 先确认目标属于当前快照；必要时选择，再打开单页 |
| 切到「单页」 | 只使用当前有效选择；无选择时入口禁用并说明原因，不自动挑第一节点 |
| 切到「Map」/单页返回 | 只切显示状态，恢复图中键盘焦点；不重新打开 Map 或重新选择同节点 |
| 点击关联条目 | 在当前 Map 内选择并打开对应真实节点；不可用目标显示说明，不制造节点或连线 |
| 单页 Esc | 返回 Map；不拦截原生对话框、输入控件或已被处理的键盘事件 |
| 换 Map/工作区/用户 | 会话动作保持原实现；展示状态按归属重置/隔离，迟到 DOM 恢复失效 |
| 当前节点被移除 | 单页显示节点不可用，并保留返回 Map 入口；不显示旧正文或自动换到其他节点 |

仅模式切换不得触发新的 map.get、branch.get、watch、租约领取/释放、Run 控制或取消；也不额外安排偏好保存。真实节点和 Map 导航可以按既有会话规则请求与释放授权。

## 5. 函数与接口清单

名称是实施约定，允许在保持职责和测试覆盖的前提下调整；不为填充清单增加单行转发函数。

### 5.1 身份与页面状态

`node-identity.ts`：

| 函数 | 输入 → 输出 | 约定 |
| --- | --- | --- |
| `nodeIdentityKey(identity)` | NodeIdentity → string | 使用无分隔符碰撞的稳定编码；不拼接可能含冒号的裸字段 |
| `nodeIdentityEquals(left, right)` | 两个 NodeIdentity/null → boolean | 比较完整身份；空值按明确规则比较，不仅比较 nodeId |

`use-workspace-view.ts`：

| 函数 | 输入 → 输出 | 约定 |
| --- | --- | --- |
| `useWorkspaceView(context)` | 只读 Ref<WorkspaceViewContext> → 页面状态及动作 | 创建模式、阅读目标和缓存，内部监听归属变化；Vue scope 结束时清理 |

| `showMap()` | 无 → void | 回到 Map，保留书签；不调用会话导航、选择或运行动作 |

| `reconcileContext(next)` | 新上下文 → void（私有） | 换用户/登出/换工作区清缓存；换 Map 回到 Map 模式；节点消失保留可返回的缺失页状态 |

模式和阅读目标对调用者只读；缓存不暴露。context 变化不调用 session。书签属于同一工作区的不同 Map 可分别存放，但旧异步恢复不能覆盖新页面。

### 5.2 单页内容

`reader-content.ts`：

| 函数 | 输入 → 输出 | 约定 |
| --- | --- | --- |
| `readerFindDefinition(node, catalog, runs)` | 节点、目录、已有 Run → 精确 DataTypeDefinition/undefined | 先匹配当前目录的 id/version，再查已有冻结目录的同一精确版本；不借最新版本解释旧数据 |
| `readerReadHeading(node, definition)` | 节点与精确定义 → string | 读取短 `titlePath`，长正文退回定义标题；视觉裁剪在组件，不修改正文 |
| `readerReadFields(node, definition)` | 节点与可选定义 → 只读字段列表 | 根据 fieldOrder/fieldLabels 和实际 payload 读取；保留完整正文和未覆盖字段，不生成默认值 |
| `readerReadRelations(snapshot, identity)` | 当前 Map 快照和目标身份 → 一跳关系列表 | 区分前置、后继、引用；使用真实 edges/payloadReferences，不从任意字符串猜 ID，不递归展开引用环 |
| `readerFormatValue(value, labels)` | JSON 值与可选枚举标签 → 展示文本 | 0/false/空字符串/null/缺失可区分，复杂值可读；不输出可执行 HTML |

字段项至少带稳定 path/key、label、原值和展示种类。标题/summary/body 不同的夹具必须证明单页使用完整 body；payloadReadNodeText 继续只承担摘要。

关系项带稳定关系键、方向、关系种类、目标 NodeIdentity、目标可用性及出处 path/edgeId。相同目标通过不同关系出现时保留语义；共享节点不复制成新业务节点。不为引用目标建立假的 successor，也不推断可信度、已读或 Run 结果。

缺少精确定义时保留原始 payload 可读回退。缺失引用目标显示“当前不可用”并禁用导航；没有 payloadReferences 时不猜测隐藏关联。源码不存在的跨图解析能力不由本函数补齐。

`NodeReader.vue`：

| 函数 | 输入 → 输出 | 约定 |
| --- | --- | --- |
| `readerCaptureBookmark()` | DOM 当前滚动位置 → bookmark 事件 | 同步记录本页位置，附完整身份；不写 localStorage 或偏好 |
| `readerRestorePosition()` | 当前身份/bookmark → Promise<void> | nextTick 后核对 active、身份与恢复代次，再设置滚动；超出新内容高度由 DOM 限幅 |
| `readerOpenRelation(item)` | 真实关联项 → open-node 事件 | 仅可用同 Map 目标发意图；页面再次验证所属身份 |
| `readerReturnToMap()` | 无 → return 事件 | 返回操作，书签已由本页同步记录，不改变选中节点 |
| `readerRequestEdit()` | 当前页面身份 → edit-node 事件 | 由父页面切回现有 Inspector，复用编辑草稿 |
| `readerCancelRestore()` | 无 → void（私有） | 身份改变、隐藏或卸载使旧恢复任务失效，并清理自有监听/观察器 |

NodeReader 的 ready、loading、unselected、missing、empty、error 为互斥展示状态。错误且有同 Map 的有效缓存时可以显示只读内容及连接提示；没有匹配数据时不得显示上一 Map 正文。

DataPayloadView 采用 Vue 文本插值或 v-text；首版不自动执行 Markdown/HTML，不自动抓 URL/附件。对象/数组先提供完整可读值，专用证据样式在 C 阶段完善。

### 5.3 画布与模式恢复

`GraphCanvas.vue`：新增 `active?: boolean`（默认 true）、`open` 事件，并按实际需要 expose `focusSelectedNode()`。

| 函数 | 调整/新增 | 约定 |
| --- | --- | --- |
| `canvasSelect(item)` | 调整 | 发送选择意图；pressed/selected 以 props.selectedId 为准，focusedId 只表达键盘焦点 |
| `canvasOpenNode(item)` | 新增 | 验证真实节点后发送打开意图；双击与 Enter 共用 |
| `canvasResetMap()` | 调整 | 只因初次挂载、真实 Map 改变或空图首次有数据请求初始化；隐藏时排队 |
| `canvasApplyPendingView()` | 新增（私有） | 正尺寸、active 且身份匹配时，先做必要初始化，再做待聚焦；同身份普通返回不 reset/fit |
| `canvasSelectKeyboard(event, id)` | 调整 | 方向键/Space 选择，Enter 打开，保留原键盘可达性 |
| `focusSelectedNode()` | 新增 | 显示后把 DOM 焦点恢复到当前节点，使用 preventScroll；没有节点时焦点落到画布或切换控件 |

画布保留 v-show 实例。隐藏期间 selectedId、节点数量、SSE 或 Map 改变仍可能触发 watcher，不能执行零尺寸聚焦。nextTick 后再次核对 Map/node 和本次操作代次；不要让旧 Map 的待操作落到新 Map。

当前 Map 里仅模式切换、内容更新、activity/审核/租约更新不请求重新初始化布局。节点改为另一个真实目标时，返回允许必要平移以定位目标，但保留缩放；同节点往返的 transform 应完全一致。

`useCanvasPanZoom.ts`：

CanvasPanZoomOptions 增加可选只读 active 引用，缺省为 true；GraphCanvas 传入自身可见状态。平移捕获由 composable 记录 pointerId，隐藏时主动结束，避免捕获仍把移动事件送到隐藏画布。

| 函数 | 处理 |
| --- | --- |
| `fitLayoutRect` | 容器缺失或宽高为零时不 reset、不改 scale/translation；可见时保留现有适应规则 |
| `focusLayoutRect` | 容器零尺寸或屏幕矩阵不可用时不改平移 |
| `layoutRectScreenBounds` | 隐藏/尺寸无效时返回 null |
| `viewCenterPoint` / `zoomAt` | 隐藏容器不据错误中心计算；可见时仍按原缩放边界工作 |
| `cancelPan()`（私有） | 隐藏、取消或卸载时结束平移，只有确实持有 pointer capture 才释放 |
| 原 pointer/wheel 与卸载处理 | 保留监听创建/移除责任，模式反复切换不重复安装 |

三维相机 API 已由当前实际场景使用，适应、缩放和 OrbitControls 随实例保留；没有新增无调用者的 readViewport/restoreViewport。模式往返通过保留场景实例与可见性保护实现，相机资源在场景卸载时释放。大图布局与性能生命周期仍需 B 阶段验证。

### 5.4 页面装配

`WorkspacePage.vue`：

| 函数/状态 | 约定 |
| --- | --- |
| `viewContext`（computed） | 从当前会话派生完整身份、选择是否有效和加载状态，无副作用 |
| `homeSelectNode(id)` | 校验当前快照；与 selectedId 相同则不重复调用 session.selectNode，否则走原动作 |
| `homeOpenNodePage(identity)` | 验证当前 Workspace/Map/Node；必要时调用同步的 selectNode，然后 openPage；不等待网络再切模式 |
| `homeSwitchView(mode)` | 仅调用本地 openPage/showMap，禁止 openMap/selectNode 或 Run 动作 |
| `homeSaveReaderBookmark(input)` | 完整身份交给本地书签动作，不修改协议或远端偏好 |
| `homeEditReaderNode(identity)` | 核对当前节点后回 Map，显示现有 Inspector，不创建另一份 draft |
| 既有 homeConnectSession/homeCreate*/homeStartRun/homeOpenImport 等 | 保留真实业务意图与当前错误处理，不因模式切换改写执行流程 |

Sidebar 发出的工作区/Map 导航继续调用现有会话动作。右栏 Inspector/RunReview 保留在模式条件之外，由 AppShell 的 v-show 处理；不能通过 v-if 重建右栏导致同节点草稿消失。

WorkspaceViews 维护 DOM 焦点恢复的短生命周期：`viewsRequestMode(mode)`、`viewsOpenNode(nodeId)`、`viewsApplyFocus()`、`viewsHandleKeydown(event)`。它只发用户意图，外部 mode 接纳后再做 DOM 焦点恢复，不自存第二份 mode。

### 6.3 隔离服务与控制函数

Playwright 的 webServer 启动独立 Vite，地址固定 `http://127.0.0.1:5174`，严格端口且不复用未知现有服务；server.fs.allow 仅放行本仓库，以便导入生产 SFC。自动关闭自有服务，启动失败报错而不改用生产地址。配置依据 [Playwright webServer](https://playwright.dev/docs/test-webserver) 和 [测试配置](https://playwright.dev/docs/test-configuration)。

Vitest 保持 Node 环境；浏览器测试用 `.e2e.ts`，Playwright testDir/testMatch 明确匹配，避免被现有 `tests/**/*.spec.ts` 发现。生产路由和生产 Vite 不新增测试路由、查询开关或全局夹具对象。

夹具函数：

| 函数 | 约定 |
| --- | --- |
| `fixtureCreateWorkspaceViews(options)` | 生成独立 GraphSnapshot/catalog/工作区/偏好；每次创建隔离数据，不复用可变单例 |
| `fixtureCreateNode/fixtureCreateEdge` | 生成明确精确类型、版本、方向与内容的节点/关系，用于边界样例 |

| `emitSnapshot(mapId, snapshot)` | 向该 Map 已注册监听发送类型化事件；支持真实页面接受和拒绝过期结果的验证 |
| `failNextRead(method, error)` | 受控失败，保留 code/status/retryable；不靠错误文案分类 |
| `deferRead(method)` | 返回可手动完成/拒绝的等待句柄，安排迟到读取，不任意 sleep |
| `readCalls()` | 返回方法、目标身份和次数的副本，验证模式切换没有新增业务动作 |

替身只实现测试场景需要的已有查询/命令，未知调用明确失败，不返回万能空对象。watch 在 AbortSignal 结束前保持受控存活，避免循环重连干扰测试；不访问任何外部 API、数据库、队列或模型。

浏览器允许测试 Vite 的页面、模块和本机资源请求，意外 `/api/v1` 或外部网络请求让用例失败。测试控制器只在测试入口暴露，类型声明也只包含在测试 tsconfig。
