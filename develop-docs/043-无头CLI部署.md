# 043 — 无头 CLI 部署

## 目标

在保留 Electron+Vue 桌面端的前提下，新增并行的 Node CLI（auto-only），供服务器无 UI 跑 Timeline。

## 架构

- 进程内 `apiBuildInprocess(): ElectronAPI` 直连 map/graph/workspace/catalog service
- 复用 `adapterBuildIpc` + `runTimeline`（不复制 adapter）
- `graphEmit` / `graphOn*` 事件总线：桌面仍 `webContents.send`，无头订阅同一总线
- 数据目录 `pathsReadDataDir()`：优先 `CHONGMING_DATA_DIR`，否则 Electron userData / `~/.chongming`

## CLI

| 命令 | 行为 |
|------|------|
| `list` | map 列表 |
| `create --kind source\|news\|claim` | 建数据节点（可 `--map`） |
| `run <mapId> [--from] [--to]` | `updateTimeline` + `runTimeline('auto')` |
| `status <mapId>` | 当前数据节点 |

输出：成功 stdout 仅最终数据节点 JSON；失败 stderr `{ ok:false, code, msg }`。

## 不做

HTTP、远程 HITL、删除桌面端。
