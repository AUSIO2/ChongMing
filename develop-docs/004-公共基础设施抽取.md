# 公共基础设施抽取设计文档

## 目标
将 `database.ts` 和 `prompt-loader.ts` 以及通用的 TypeScript 类型抽取到 `electron/shared/` 目录下，使 `fact-extractor` 和 `fact-verifier` 两个模块能够对等地复用公共基础设施，消除模块间的循环依赖和不合理的跨模块相对导入。

## 目录结构设计
调整后的 `electron` 结构如下：
- `electron/shared/`
  - `types.ts` (包含 Confidence, Priority, SubAgentConfig, RouteInstruction, NewsContext 等共享类型)
  - `database.ts` (公共 newsDocumentSchema、Mongoose 数据库连接及 NewsModel)
  - `prompt-loader.ts` (公共 prompt 载入与渲染工具函数)
- `electron/fact-extractor/`
  - `types.ts` (拆分专有类型：RawClaim, SplitClaim, SplitGraphConfig...)
  - `extractor.ts` (拆分图 LangGraph 编排)
  - `index.ts` (拆分模块导出)
- `electron/fact-verifier/`
  - `types.ts` (核查专有类型：SubAgentOpinion, VerifyResult, VerifyGraphConfig)
  - `verifier.ts` (核查图 LangGraph 编排)
  - `index.ts` (核查模块导出)

## 验证计划
- 运行 `npx tsc --noEmit` 确保整个项目编译通过，没有任何导入路径或者类型定义错误。
