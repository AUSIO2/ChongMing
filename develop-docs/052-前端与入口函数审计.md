## 6. 新增客户端与入口函数清单

以下函数仅连接已经确定的 050/051 架构，不引入额外调度层。公共命令/DTO 的完整字段由主接口文档定义，不能让 UI 自行拼 DSH 或 Mongo 内部参数。

### 6.1 client/api.ts 与 src/api.ts

| 目标函数 | 职责与边界 |
|---|---|
| `clientRead(query, options?)` | 带身份的图查询，解析结构化业务错误；返回公共 DTO |
| `clientDispatch(envelope, options?)` | 发一次业务 mutation；不自动重放；响应未知时保留 request/entity ID 供查询确认 |
| `clientReadControl(query, options?)` | Workspace/profile/能力/设置/健康查询 |
| `clientDispatchControl(envelope, options?)` | 配置、权限、导入导出控制；身份由连接凭证确定 |
| `clientWatch(mapId, listener, options?)` | 带 Authorization 的 fetch SSE，首次/重连取完整基线，支持取消，断线退避；不自动把 Activity 当快照 |
| `clientUploadAsset(input, content, options?)` | 发送文件元数据/字节，完成后返回 ready assetId 和摘要；不把 path 当可共享资产 |
| `clientClose()` | 关闭客户端订阅和本地请求；不取消远端 Run |
| `src/api.ts: read/dispatch/watch/readControl/dispatchControl/uploadAsset` | Vue 的唯一调用入口；Desktop 走受限 preload，Web 走相同公共 HTTP client；不读 Node/Electron/DSH 私有类型 |

`watch` 的返回值应是可立即调用的取消函数；异步连接/重连状态通过事件或单独连接状态传达。内部网络帧可携带 operation/fence/seq 用于隔离旧 owner；Renderer 只需要经协议规范化的公开 Activity 标识和代数，不需要 sessionId、holder 凭证或执行权。

必须保留：工作区创建/切换和本地 Agent 导入；Map 侧栏列表、改名/删除、多标签；Source/News/Claim 独立创建；正文编辑；Agent 配置、优先级/hint 与批量更新；声明去重；自动/人工模式、运行/取消/出错可重试；候选/已保存/置信度/来源/AI 可见上下文；节点选中、方向键、运行快捷键；缩放/平移/自适应/自动对焦；可拖拽面板和折叠侧栏；模型/工具/提示词/注入变量/返回格式配置；连接状态与测试；图和工作区导入导出公开能力。

下列是真实缺口或旧架构行为，迁移时要修正，不应照搬为需求：

1. **模式在无 Run 时不能保存。** UI mode 来自 `snapshot.run?.mode` 的旧投影默认，store.setMode 总调用 run.set-mode；后端无 Run 即报错。[flow-map.ts:42](/Users/xiong/ChongMing/src/stores/flow-map.ts:42)、[service.ts:501](/Users/xiong/ChongMing/electron/mapper/service.ts:501)。目标需要本地 runOptions。
