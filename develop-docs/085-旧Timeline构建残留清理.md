# 085 — 旧 Timeline 构建残留清理

日期：2026-10-06。范围：清理已退役执行设计的构建残留和过时需求描述；前端阶段安排继续维护在 [082](./082-前端图工作台与阅读视图重构计划.md)。

## 当前证据

运行源码、契约和现有界面不再依赖 Timeline。`dist-electron` 仍有三个旧 main 哈希文件及其三个 local-agent-service 文件，另有旧 `main.cjs`、`preload.mjs`。当前 package.main 指向 `dist-electron/main.js`，当前 main/preload 不引用这些旧文件。

现有打包清单 `dist-electron/**/*` 会携带这些闲置文件。当前产物还含已从源码移除的旧错误文案，需正常重建覆盖。早期需求草案已经退出主线，其时间线待办和原文可从Git历史追溯。

## 实施与不变式

1. 在仓库外备份 dist、dist-electron，以及本次修改的现有配置和文档，记录文件摘要。
2. 再次确认当前入口不引用旧文件，移除八个已确认的旧构建产物。
3. 桌面打包只包含当前 `main.js` 与 `preload.js`；当前两入口构建为独立文件，不依赖其他本地产物。
4. 历史需求文档增加说明，移除旧时间线待办；六份 Timeline 专属设计/实施记录标明已退役并保留追溯内容。
5. 正常 Vite 构建覆盖当前产物，核对不存在旧 Timeline、阶段游标与旧 until 文案；执行架构/消息边界和差异检查。

保留现有未提交改动、Operation、Run 历史、显式迁移和用户数据库。不修改历史发行安装包，也不将构建清理表述为数据库迁移。前端第一阶段仅细化计划，不在本次开始功能实现。

## 验证与恢复

核对当前桌面/页面入口及本地产物引用，验证打包文件清单和构建结果；新构建若增加本地入口依赖，应更新清单后再交付。备份路径、清理文件、首次失败及复验结果记录在 [实施记录](./085-implement-旧Timeline构建残留清理.md)。恢复时只按需要取回具体文件，不整体覆盖其他进行中的改动。
