# 071 — 函数用途中文注释

## 目标

为运行代码中的每个可命名函数和方法补一条简短中文用途注释，帮助读者在进入实现前知道函数负责什么。

## 范围

- 扫描 `apps/`、`backend/`、`client/`、`contracts/`、`platform/` 和 `scripts/` 下的 TypeScript、Vue 脚本及 MJS。
- 覆盖函数声明、类方法、对象方法和构造函数；匿名箭头回调不单独添加模板化废话，依靠所在的具名函数表达上下文。
- 已有明确用途注释的函数不重复堆叠；新增注释统一使用 `// 用途：……。`。

## 规则

- 注释说明业务动作和结果，不复述函数名，不描述实现细节。
- 审计、边界检查和测试脚本也使用中文说明，避免只有业务代码可读。
- 不改变运行逻辑、导出接口、错误文案或测试行为。

## 验收

- 具名函数和方法的前置用途注释覆盖率为100%。
- TypeScript、架构边界、消息检查和现有测试继续通过。
