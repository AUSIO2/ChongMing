# 011 — 用途前缀类型命名（Purpose + Entity）

## 目标

类型名统一为「用途前缀 + 实体」，一眼区分所在层，避免 `RawClaim` / `SplitClaim` / `ClaimParams` 等同义混用。

## 用途前缀

| 前缀 | 含义 |
|------|------|
| `Map` | Map Port 拓扑节点与节点参数 |
| `Display` | 渲染进程文档/列表 DTO |
| `Graph` | LangGraph 运行态 |
| `Persist` | Mongo 落库形状 |
| `Catalog` | SubAgent 注册表 / 可选目录 |
| `Agent` | 运行时 LLM 配置 |

基础枚举 `Priority` / `Confidence` / `ExecutionMode` / `PromptConfig` 不加前缀。

## 非目标

- 不改图 state **字段名**（如 `routeInstructions`），仅改类型名，降低运行时风险
- 不改 Vue 组件名、IPC channel 字符串、store id
- 不改 `NewsContext` / `VisibleContext` / `ContextField`（跨层基础结构，本轮不动）
