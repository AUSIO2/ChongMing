# 063 — 执行活动接口

## Host → API

POST /internal/v1/activity，内部Bearer认证；使用与data工具相同的x-work-id、x-work-holder、x-work-fence授权头。

正文只允许mapId、status、sequence。status取preparing/model/tool/result；sequence为同一次领取中从1递增的安全整数。API验证尚可执行的工作和租约，并从配置快照派生runId、operationId、nodeId、actor、agentName。未知字段/状态返回400；无有效租约返回409；MQ不可用返回503。上报不写图、不改变revision。

## MQ → API → 客户端

复用现有change fanout，kind为activity。内部消息包含holderId用于接收API再次验证租约；该字段不进入客户端事件。

认证Map SSE在snapshot首帧后可发送：
- type: activity
- items: GraphActivity[]，当前合法活动的完整列表，空列表清空显示。

GraphActivity字段：mapId/runId/operationId/nodeId/workId、actor、agentName、status、fence、sequence、updatedAt。只展示固定状态摘要；不包含模型文本、推理、工具参数/结果或模型会话身份。

每API最多缓存1000项，按work保留最高fence及sequence；发出列表前验权并重新验证当前工作。图变化和SSE心跳会移除已失效的活动。Host续租重报当前状态；API重启后不回放执行上下文，等待新上报。状态列表不承担工作历史或断点职责。

Web和Electron共用现有GraphStreamEvent通道，无新增Renderer权限。
